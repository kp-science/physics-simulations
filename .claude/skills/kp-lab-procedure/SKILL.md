# วิธีการทดลองแบบมีภาพ (KP Science Virtual Lab)

ต้นแบบที่ครูยอมรับแล้ว: **Lab 60 มิลลิแกน** (`_admin/lab_guides/vpl02-lab-60.py`) — เปิดดูก่อนเขียนแลปใหม่ทุกครั้ง

## หลักที่ครูกำหนด (จากคำติจริง)

1. **อธิบายครบกระบวนการ** ตั้งแต่เตรียม → วัด (อ่าน/จับค่ายังไง) → บันทึกลงใบบันทึก → โปรแกรมคำนวณอะไรต่อ (สูตรเป็นลำดับ) → อ่านตาราง → ทำซ้ำ/เปลี่ยนตัวแปร → วิเคราะห์ (กราฟ/ความชัน/ค่าเฉลี่ย) → ผลสุดท้าย
2. **ทุกขั้นที่ได้ตัวเลข ต้องมี `out`** บอกว่าได้ค่าอะไร หน่วยอะไร (กล่องเขียว "📌 ได้ค่า") — ขั้นวิเคราะห์ต้องบอกค่าที่คาดว่าจะได้ เช่น e ≈ 1.60 × 10⁻¹⁹ C
3. **ไม่ทำส่วน "ปุ่มต่าง ๆ ทำอะไร"** — ครูบอกไม่จำเป็นถ้าอธิบายครบกระบวนการ (ปุ่มที่ต้องใช้ให้พูดถึงในขั้นที่ใช้)
4. **มันคือวิธีการทดลอง** — วางในแถบ "วิธีการทดลอง" เดิมใต้หัวข้อ "ขั้นตอน" (kp-labmode.js ทำให้เอง และซ่อนรายการข้อความเดิม) ไม่สร้างแถบใหม่
5. ภาษาตามหนังสือ สสวท. (ดู memory: ipst-em-terms, ipst-magnification-sign) · ประโยคสั้น · 1 ขั้น = 1 การกระทำหลัก · ปกติ 8–14 ขั้น

## ขั้นตอนทำงาน

1. **อ่านแลป** (`_admin/labs_data.py` → path): แถบ `#tab-proc` (วัตถุประสงค์ · การใช้งาน · ขั้นตอน · วิธีคำนวณ) = เนื้อหาตั้งต้น · แล้วหาในสคริปต์: ฟังก์ชันบันทึก (`record`/`addRow`…) · ฟังก์ชันคำนวณ · ตัวแปรสถานะระดับบนสุด (`let`) · id ของแผง/ตาราง/กราฟ/ช่องกรอก · `window.KP_TUTOR` (บอกลำดับการกดที่ถูก)
2. **เขียนไฟล์** `_admin/lab_guides/<ชุด>-lab-<เลข>.py` (ชื่อ = access string ตัด `vlab:` แล้วแทน `:` ด้วย `-` เช่น `vpl06-lab-108.py`) — 1 แลป 1 ไฟล์ ทำหลายแลปพร้อมกันได้ไม่ชนกัน:
   ```python
   # -*- coding: utf-8 -*-
   GUIDE = {
     'title': 'ชื่อกระบวนการ (เช่น หาความต้านทานจากกราฟ V–I)',
     'setup': r"""JS รันครั้งเดียว: ฟังก์ชันช่วยสร้างข้อมูลจากแบบจำลองฟิสิกส์ของแลป""",
     'steps': [ { 'el': '#id' หรือ ['#a', '#b'],      # กรอบเหลือง (ต้องมองเห็นได้)
                  'prep': "JS ตั้งสภาพแลปก่อนถ่าย",   # เรียกฟังก์ชันของแลปเอง
                  'title': 'ทำอะไร', 'text': 'วิธีทำ + เหตุผล (HTML)', 'out': 'ค่าที่ได้' }, ... ] }
   ```
   (เลขที่ใช้กับสคริปต์ = เลข Exp ใน labs_data เช่น `60`, `6.1`, `32B` หรือใช้ชื่อไฟล์ `vpl02-lab-32b`)
   - `prep` ใช้ฟังก์ชัน/ตัวแปรของแลปเอง (เช่น `spray()`, `setV()`, `toggleField()`, `rows.push(...)`, `renderTable()`, `drawGraph()`) — ตัวแปร `let` ระดับบนสุดอ่านแก้ได้ตรง ๆ
   - **ข้อมูลในตาราง/กราฟต้องมาจากแบบจำลองฟิสิกส์ของแลป** (เรียกสูตร/ฟังก์ชันในไฟล์ + noise เล็กน้อย) ห้ามแต่งตัวเลขเอง — ค่าที่ได้ต้องสอดคล้องกัน (เช่น q เป็นจำนวนเต็มเท่าของ e)
   - ขั้นสุดท้ายของการวิเคราะห์ควรตั้งสภาพให้เห็น "คำตอบ" (เส้นตรงฟิตแล้ว, ค่าความชัน, ค่าเฉลี่ย)
   - `alert`/`confirm` ถูกปิดให้แล้วตอนถ่าย
3. **ถ่ายภาพ**: `python3 _admin/capture_lab_guide.py <เลข>` → `assets/guides/<slug>/` + เพิ่มลง `assets/guides/index.json`
   - `s` = ผ่าน · `E` = prep error (ข้อความแสดงท้าย) · `?` = หาเป้าหมายไม่เจอ/มองไม่เห็น → แก้แล้วรันใหม่
   - ดีบัก: `KPG_KEEP=/tmp/x python3 _admin/capture_lab_guide.py <เลข>` เก็บภาพดิบเต็มจอ
4. **ตรวจภาพทุกภาพ** (สำคัญ — ห้ามข้าม): ทำ contact sheet แล้วเปิดดู
   ```bash
   python3 - <<'EOF'
   from PIL import Image, ImageDraw; import glob
   fs=sorted(glob.glob('assets/guides/<slug>/step-*.jpg'), key=lambda f:int(f.split('-')[-1][:-4]))
   S=Image.new('RGB',(4*360,((len(fs)+3)//4)*330),(30,30,30)); d=ImageDraw.Draw(S)
   for i,f in enumerate(fs): im=Image.open(f); im.thumbnail((356,326)); S.paste(im,((i%4)*360,(i//4)*330)); d.text(((i%4)*360+4,(i//4)*330+4),str(i+1),fill=(255,0,0))
   S.save('<scratchpad>/sheet.jpg')
   EOF
   ```
   เช็ค: กรอบเหลืองอยู่ที่เป้าหมายจริง · ค่าบนจอ/ตารางตรงกับที่ข้อความบอก · ภาพ 3D วาดแล้ว (ไม่ดำ/ว่าง) · ตาราง/กราฟมีข้อมูล · อ่านตัวเลขออก
5. **ดูในเบราว์เซอร์**: preview `phys` → เปิดแลป → แถบวิธีการทดลอง (เติม `?fresh=N` กันแคช) ทั้ง 1280 px และ 375 px
6. บันทึก `SESSION_LOG.md` · commit เฉพาะ `_admin/lab_guides/<slug>.py` + `assets/guides/` (ถ้าแก้ `_shared/kp-labmode.js` ต้องรัน `python3 _admin/bump_auth_version.py`)

## ข้อควรรู้ (เจอมาแล้ว)

- แผงควบคุมขวาหลายแลปเลื่อนได้เอง (`overflow:auto`, สูงจำกัด) — สคริปต์ใช้ `scrollIntoView` ให้แล้ว ถ้าเป้าหมายอยู่ในแผงยังมองไม่เห็น ให้ใช้ selector ของตัวที่อยู่ในแผงจริง
- selector ต้องชี้ตัวที่**มองเห็น** (ตัวแรกที่ตรง) — ปุ่มซ้ำกันหลายที่ (เช่น `resetLab()` ในแถบภาพ + แผง) ระบุให้ชัดด้วย id/ตัวแม่
- ภาพ 3D ต้องรอวาด — สคริปต์รอ 900 ms หลัง prep · ถ้ายังไม่ทัน ให้ prep เรียกฟังก์ชันวาดของแลป (`drawAll()`)
- headless วาดเงาใหญ่ไม่ออก → สคริปต์วาดส่วนมืด + กรอบเหลืองเองใน Python
- แลปไม่มี `#tab-proc` (มีราว 33 จาก 167) → kp-labmode สร้างแถบ "📸 วิธีใช้แลป" ให้แทน
- ข้อมูลสุ่มใหม่ทุกครั้งที่ถ่าย — ถ้าอยากให้คงที่ ใช้ค่าคงที่ใน setup
- ตัวกันสิทธิ์ (`kpPageAccess`) ถูกปิดเฉพาะใน browser ที่ถ่ายภาพ ไฟล์จริงไม่ถูกแตะ
