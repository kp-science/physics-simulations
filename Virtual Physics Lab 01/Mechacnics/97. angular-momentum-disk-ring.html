วัตถุประสงค์

เมื่อจบการทดลองนี้ นักเรียนสามารถ

  1. หาความเร็วเชิงมุมของจานจากคาบการหมุนที่ประตูแสงบันทึกได้ ก่อนและหลังวางวัตถุลงบนจาน
  2. ตรวจสอบว่าโมเมนตัมเชิงมุม L = Iω ก่อนและหลังวางมีค่าเท่ากัน ขณะที่พลังงานจลน์การหมุนลดลง
  3. หาโมเมนต์ความเฉื่อยของวัตถุจากอัตราส่วนคาบ และเทียบกับค่าจากสูตร
  4. ตรวจสอบทฤษฎีบทแกนขนาน I = Icm + Md² ด้วยการวางวงแหวนเยื้องศูนย์กลาง
  5. หามวลของวงแหวนปริศนา X

อุปกรณ์ (เสมือนจริง)

  • จานอะลูมิเนียม M = 1.500 kg รัศมี 12.0 cm หมุนในแนวระดับบนลูกปืน · มีแถบสะท้อนแสงหนึ่งแถบที่ขอบล่างของจาน
  • ประตูแสงใต้ขอบจาน + จอบันทึก แสดงเวลาที่แถบผ่านและคาบของแต่ละรอบ (ละเอียด 0.0001 s) · หยุดบันทึกเองเมื่อครบ 6 รอบหลังวางวัตถุ
  • วงแหวนเหล็ก 1.400 kg (R₁ = 5.40 cm, R₂ = 6.40 cm) · แท่งเหล็ก 0.600 kg ยาว 24.0 cm · วงแหวนปริศนา X (ขนาดเท่าวงแหวนเหล็ก)
  • แขนจับวัตถุเหนือจาน ตั้งตำแหน่งได้ 3 ตำแหน่ง d = 0, 2.5, 5.0 cm จากแกน · ปล่อยวัตถุตกลงสูง 3 cm

ขั้นตอน

ตอน ก: วงแหวนเหล็กที่กลางจาน

  1. เลือก ⭕ วงแหวนเหล็ก ตำแหน่ง กลางจาน · กด 🌀 ปั่นจาน (หรือลากขอบจานแล้วปล่อย)
  2. รอให้จอบันทึกขึ้นคาบอย่างน้อย 2–3 รอบ แล้วกด ▼ วางวัตถุ
  3. กด 📟 จอบันทึกคาบ อ่าน T₁ = คาบของรอบสุดท้ายก่อนค่ากระโดด และ T₂ = คาบของรอบแรกหลังจากค่ากลับมานิ่ง (ข้ามรอบที่คร่อมจังหวะวาง) · บันทึก
  4. กด ↩ ยกออก ปั่นใหม่ด้วยความเร็วต่างกัน ทำซ้ำอย่างน้อย 3 ครั้ง · ดูในตาราง ① ว่า L หลัง/ก่อน ≈ 100% แต่ Ek หลัง/ก่อน ต่ำกว่า 100%

ตอน ข: แท่งเหล็ก

  1. เลือก ➖ แท่งเหล็ก ที่กลางจาน ทำซ้ำ · เทียบ I ที่วัดได้กับ ML²/12

ตอน ค: วางเยื้องศูนย์กลาง (ทฤษฎีบทแกนขนาน)

  1. ใช้วงแหวนเหล็ก ที่ d = 2.5 cm และ 5.0 cm อย่างละ 1 ครั้งขึ้นไป · ดูกราฟ I – d² ความชันควรเท่ามวลวงแหวน 1.40 kg

ตอน ง: วงแหวนปริศนา X

  1. เลือก ❓ วงแหวน X ที่กลางจาน ทำอย่างน้อย 3 ครั้ง · IX = Iจาน(T₂/T₁ − 1) · MX = 2IX/(R₁² + R₂²)
⚠️ อ่านคาบจากจอบันทึกในภาพ 3D เอง — โหมดวัดค่าเองไม่บอกค่าให้ · รอบที่คร่อมจังหวะวาง (ส่วนหนึ่งเร็ว ส่วนหนึ่งช้า) ใช้ไม่ได้ · จานช้าลงเล็กน้อยทุกรอบจากแรงเสียดทานที่ลูกปืน จึงควรใช้รอบที่อยู่ติดกับจังหวะวางมากที่สุด

คำถามท้ายการทดลอง

  1. โมเมนตัมเชิงมุมก่อนและหลังวางเท่ากันหรือไม่ ทำไมจึงอนุรักษ์ ทั้งที่มีแรงเสียดทานระหว่างวัตถุกับจาน
  2. พลังงานจลน์การหมุนหายไปไหน เปรียบเทียบกับการชนแบบไม่ยืดหยุ่นในการเคลื่อนที่แนวตรง
  3. ทำไมวางวงแหวนเยื้องศูนย์กลางแล้วจานช้าลงมากกว่าวางที่กลางจาน
  4. วงแหวนกับแท่งเหล็กมวลเท่ากัน ชิ้นใดทำให้จานช้าลงมากกว่ากัน เพราะเหตุใด
  5. นักกีฬากระโดดน้ำม้วนตัวกลางอากาศเพื่อหมุนเร็วขึ้น ใช้หลักการเดียวกันอย่างไร

1. โมเมนตัมเชิงมุม

วัตถุที่หมุนรอบแกนตรึงมีโมเมนตัมเชิงมุม L = Iω · เมื่อไม่มีทอร์กภายนอกกระทำต่อระบบ (หรือมีน้อยมาก) โมเมนตัมเชิงมุมรวมของระบบจะคงตัว

Στภายนอก = ΔL / Δt → ถ้า Στภายนอก = 0 แล้ว L ก่อน = L หลัง
Iจาน ω₁ = (Iจาน + Iวัตถุ) ω₂

แรงเสียดทานระหว่างวัตถุกับจานเป็นแรงภายในระบบ: ทอร์กที่จานกระทำต่อวัตถุเท่ากับทอร์กที่วัตถุกระทำต่อจาน แต่ทิศตรงข้าม โมเมนตัมเชิงมุมจึงถ่ายจากจานไปยังวัตถุโดยผลรวมไม่เปลี่ยน

2. หาโมเมนต์ความเฉื่อยจากคาบ

ω = 2π / T → ω₁/ω₂ = T₂/T₁
Iวัตถุ = Iจาน (ω₁/ω₂ − 1) = Iจาน (T₂/T₁ − 1)
Iจาน = ½ M R² = ½ (1.500)(0.120)² = 1.080 × 10⁻² kg·m²

3. พลังงานจลน์การหมุนไม่อนุรักษ์

Ek = ½ I ω² = L² / 2I
Ek หลัง / Ek ก่อน = Iจาน / (Iจาน + Iวัตถุ) = ω₂/ω₁
ส่วนที่หายไป = Iวัตถุ / (Iจาน + Iวัตถุ) (กลายเป็นความร้อนจากการไถลช่วงสั้น ๆ)

4. สูตรโมเมนต์ความเฉื่อยและทฤษฎีบทแกนขนาน

วงแหวนหนา (แกนผ่านศูนย์กลาง ตั้งฉากกับระนาบ): Icm = ½ M (R₁² + R₂²)
แท่งบาง (แกนผ่านกึ่งกลาง ตั้งฉากกับแท่ง): Icm = M L² / 12
จานตัน: I = ½ M R²
ทฤษฎีบทแกนขนาน: I = Icm + M d²
💡 แบบจำลอง: g = 9.8 m/s² · ลูกปืนมีทอร์กแรงเสียดทานเล็กน้อยคงตัว (จานช้าลงราว 0.3–0.5% ต่อวินาที จึงได้ L หลัง/ก่อน ต่ำกว่า 100% เล็กน้อย) · วัตถุตกจากความสูง 3 cm แล้วไถลบนจาน (μ = 0.35) จนหมุนไปด้วยกัน ใช้เวลาราว 0.1–0.3 s · ช่วงไถลคำนวณแบบอนุรักษ์โมเมนตัมเชิงมุมระหว่างจานกับวัตถุ · มวลวงแหวน X สุ่มต่อการเปิดหน้า
