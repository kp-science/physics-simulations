วัตถุประสงค์

ศึกษาภาพที่เกิดจากเลนส์นูน (converging lens / double convex lens) โดยแบ่งเป็น 2 ส่วน:

  • Part A: หาความยาวโฟกัส (focal length) ของเลนส์นูนด้วยแสงขนาน (แสงอาทิตย์)
  • Part B: ศึกษาตำแหน่ง ขนาด และชนิดของภาพเมื่อวัตถุอยู่ที่ระยะต่าง ๆ จากเลนส์ และตรวจสอบสมการเลนส์บาง 1/f = 1/do + 1/di

อุปกรณ์ (เสมือนจริง)

  • เลนส์นูน (double convex lens) เส้นผ่านศูนย์กลาง ~6 cm ทางยาวโฟกัส f ≈ 5–30 cm พร้อมตัวยึดเลนส์
  • ม้านั่งเชิงแสง (optical bench) หรือไม้เมตร 100 cm — อ่านตำแหน่งจากสเกลบนแผนภาพ
  • วัตถุ: แผ่นลูกศรเรืองแสง (แทนหลอดไฟเล็ก) สูง h ปรับได้ 1–8 cm
  • จอรับภาพสีขาว (กระดาษแข็ง/แผ่นพลาสติกขุ่น) พร้อมตัวยึดจอ
  • ตา 👁 สำหรับสังเกตภาพเสมือน (มองผ่านเลนส์จากด้านตรงข้ามวัตถุ)

การใช้งาน Simulation

  • ภาพ 3D: ลากที่ว่าง = หมุนมุมมอง · ล้อเมาส์ = ซูม · ลากวัตถุ / เลนส์ / จอ / ตา ในภาพ เพื่อเลื่อนตามแนวแกน · ปุ่ม "มุมข้าง / มุมเฉียง / มุมจากตา"
  • แผนภาพรังสี 2D (ตามสเกล): ลากอุปกรณ์บนแผนภาพได้เช่นกัน อ่านตำแหน่งจากสเกล cm ด้านล่าง · ใช้ไม้บรรทัด ↔ / ↕ วัดระยะและความสูง (สเกลแนวตั้งขยาย 2.5× แต่ไม้บรรทัดชดเชยให้แล้ว)
  • สไลเดอร์ตำแหน่ง ในแผงขวา ใช้แทนการลากได้ (สะดวกบน iPad)
  • กล่องมุมขวาบนของภาพ 3D: Part A = "วงแสงบนจอ" · Part B ภาพจริง = "ภาพบนจอ" (มีวัตถุอ้างอิงเทียบขนาด) · ภาพเสมือน = "มุมมองของตา" (มองผ่านเลนส์)
  • โหมดวัดเอง (ดีฟอลต์) ไม่แสดงรังสีและตำแหน่งภาพ ต้องหาเองด้วยจอ/ตา แล้วอ่านค่าจากสเกล · โหมดอัตโนมัติ แสดงรังสีหลัก 3 เส้น ภาพ และค่าคำนวณ

Part A — หาความยาวโฟกัสของเลนส์นูน

หลักการ

ความยาวโฟกัสของเลนส์ คือ ระยะจากเลนส์ถึงจุดที่รังสีขนาน (จากวัตถุที่อยู่ไกลมาก เช่น ดวงอาทิตย์) หักเหผ่านเลนส์แล้วไปรวมกันเป็นจุด (จุดโฟกัสหลัง F′) ซึ่งอยู่อีกด้านหนึ่งของเลนส์

วิธีการทดลอง

  1. เลือก A: หาโฟกัส — แสงอาทิตย์ (แสงขนาน) ส่องจากด้านซ้ายผ่านเลนส์ไปยังจอทางขวา
  2. ลากจอไปมาทางขวาของเลนส์ ดูกล่อง "วงแสงบนจอ" — เมื่อวงแสงเล็กที่สุดเป็นจุด = จออยู่ที่จุดโฟกัส
  3. อ่านตำแหน่งเลนส์และจอจากสเกล (หรือใช้ไม้บรรทัด ↔) → f = ตำแหน่งจอ − ตำแหน่งเลนส์
  4. กรอก f ที่วัดได้ในตาราง กด "บันทึก" → กด 🎲 สุ่มเลนส์ใหม่ ทำซ้ำรวม 3 ครั้ง
⚠️ ข้อควรระวัง: ถ้าใช้ดวงอาทิตย์จริง จุดโฟกัสร้อนมาก ระวังอย่าให้แสงโฟกัสเผาจอหรือมือ และห้ามมองดวงอาทิตย์ผ่านเลนส์

Part B — ศึกษาภาพที่ระยะวัตถุต่าง ๆ

หลักการ

เมื่อวัตถุอยู่ที่ระยะต่าง ๆ จากเลนส์นูน ภาพที่เกิดขึ้นจะมีลักษณะต่างกัน ทั้งตำแหน่ง ขนาด และทิศทาง สามารถตรวจสอบได้ด้วยสมการเลนส์บาง 1/f = 1/do + 1/di

วิธีการทดลอง — ภาพจริง (do > f)

  1. เลือก B: ศึกษาภาพ ตั้งค่า f และความสูงวัตถุ h ในแผงขวา
  2. วางวัตถุที่ระยะ do > f ทางซ้ายเลนส์ (ลองทั้ง do > 2f, = 2f และ f < do < 2f)
  3. ลากจอ (อยู่ทางขวาเลนส์ คนละด้านกับวัตถุ) จนภาพในกล่อง "ภาพบนจอ" คมชัดที่สุด — ภาพจะปรากฏบนจอในภาพ 3D ด้วย
  4. วัด do (วัตถุ→เลนส์), di (เลนส์→จอ), ho, hi ด้วยสเกล/ไม้บรรทัด แล้วกรอก 4 ค่า → "บันทึก"
  5. ระบบคำนวณ f จาก do, di เทียบกับ f จริง และ M = hi/ho เทียบกับ di/do

วิธีการทดลอง — ภาพเสมือน (do < f)

  1. ลากวัตถุเข้าใกล้เลนส์ให้ do < f — จอรับภาพไม่ได้ กล่องจะเปลี่ยนเป็น "มุมมองของตา"
  2. ตา 👁 อยู่ทางขวาของเลนส์ (ด้านตรงข้ามวัตถุ) มองผ่านเลนส์ไปยังวัตถุ จะเห็นภาพหัวตั้ง ขยาย อยู่ด้านเดียวกับวัตถุ (หลักของแว่นขยาย)
  3. ตำแหน่งภาพเสมือนแสดงเป็นลูกศรเส้นประสีม่วงด้านซ้ายเลนส์ — วัด di, hi แล้วใส่เครื่องหมาย ลบ
💡 เทคนิค: ลองวางวัตถุที่ระยะต่าง ๆ — do > 2f, = 2f, ระหว่าง f กับ 2f, = f, < f
⚠️ เมื่อ do ≈ f จะหาภาพยากมาก (รังสีออกจากเลนส์ขนานกัน ภาพอยู่ไกลมากหรือไม่เกิดเลย) · เมื่อ do = 2f ภาพจริงเกิดที่ 2F′ ขนาดเท่าวัตถุ กลับหัว

คำถามท้ายการทดลอง

  1. เพราะเหตุใดจอรับภาพจึงต้องอยู่คนละด้านกับวัตถุ (ต่างจากกระจกเว้าที่จออยู่ด้านเดียวกับวัตถุ)?
  2. วัตถุอยู่ที่ 2F ภาพเกิดที่ใด มีขนาดและทิศทางอย่างไร ตรงกับผลการทดลองหรือไม่?
  3. ทำไมเมื่อ do < f จึงจับภาพบนจอไม่ได้ แต่ตามองผ่านเลนส์เห็นได้? ภาพนี้อยู่ที่ไหน?
  4. กราฟ 1/di กับ 1/do ควรเป็นเส้นตรงความชันเท่าใด และหาค่า f จากกราฟได้อย่างไร?

1. เลนส์นูนและจุดโฟกัส

เลนส์นูนหนากลางบางขอบ หักเหรังสีขนานแกนหลักให้ไปรวมกันที่จุดโฟกัส F′ อีกด้านหนึ่งของเลนส์ ที่ระยะ f จากเลนส์ · เลนส์มีจุดโฟกัส 2 จุดสมมาตรกัน (F หน้าเลนส์ และ F′ หลังเลนส์)

รังสีขนานแกนหลักหักเหผ่าน F′ — นี่คือหลักของ Part A (ดวงอาทิตย์อยู่ไกลมาก รังสีจึงขนาน)

2. รังสีหลัก 3 เส้น (Principal Rays)

เลนส์นูน (converging lens) หักเหแสงให้รวมกัน เราใช้รังสีหลัก 3 เส้นจากปลายวัตถุเพื่อหาตำแหน่งภาพ:

docm(f = 10 cm)
  • รังสี 1 (แดง): ขนานแกนหลัก → ผ่านเลนส์ → หักเหผ่านจุดโฟกัสหลัง F′
  • รังสี 2 (เขียว): ผ่านจุดศูนย์กลางเลนส์ → ตรงไปไม่หักเห
  • รังสี 3 (น้ำเงิน): ผ่านจุดโฟกัสหน้า F → ผ่านเลนส์ → ออกขนานแกนหลัก

จุดที่รังสีทั้ง 3 ตัดกัน (หรือแนวต่อย้อนกลับของรังสีตัดกันด้านวัตถุ) คือตำแหน่งภาพ

3. ภาพ 5 กรณี ตามระยะวัตถุ

ลักษณะของภาพเปลี่ยนตามระยะวัตถุ do เทียบกับ f:

กรณีระยะวัตถุ doระยะภาพ diชนิดทิศทางขนาดM
1do > 2f+ (f < di < 2f)จริงกลับหัวเล็กกว่า0 < M < 1
2do = 2f+ (2f)จริงกลับหัวเท่ากันM = 1
3f < do < 2f+ (> 2f)จริงกลับหัวใหญ่กว่าM > 1
4do = f∞ไม่เกิดภาพ (รังสีขนาน)
5do < f− (|di| > do) ด้านวัตถุเสมือนหัวตั้งใหญ่กว่าM < −1

4. สมการเลนส์บาง (Thin Lens Equation)

1/f = 1/do + 1/di M = hi/ho = di/do
  • f = ทางยาวโฟกัส — f > 0 เลนส์นูน (converging) ✅ ใช้ในการทดลองนี้ · f < 0 เลนส์เว้า (diverging)
  • do = ระยะวัตถุ (เป็นบวกเสมอเมื่อวัตถุอยู่หน้าเลนส์)
  • di, hi, M เป็น + พร้อมกัน → ภาพจริง (กลับหัว) · เป็น − พร้อมกัน → ภาพเสมือน (หัวตั้ง)
  • |M| > 1 ใหญ่กว่า · |M| = 1 เท่ากัน · |M| < 1 เล็กกว่า

กราฟ 1/do vs 1/di

จากสมการ 1/di = −(1/do) + 1/f → เมื่อ plot 1/do บนแกน x กับ 1/di บนแกน y จะได้เส้นตรงความชัน −1 ตัดแกนทั้งสองที่ 1/f จึงหาค่า f ได้จากจุดตัดแกน

🔍 เทียบกับกระจกเว้า (Lab 46): สมการและกรณีภาพเหมือนกันทุกประการ ต่างกันที่ภาพจริงของเลนส์เกิดอีกด้านหนึ่งของเลนส์ (แสงผ่านไป) ส่วนกระจกภาพจริงเกิดหน้ากระจกด้านเดียวกับวัตถุ (แสงสะท้อนกลับ)
