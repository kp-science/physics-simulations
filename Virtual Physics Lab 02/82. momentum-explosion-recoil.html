วัตถุประสงค์

  • ตรวจสอบกฎการอนุรักษ์โมเมนตัมเมื่อวัตถุที่อยู่นิ่งดีดตัวแยกจากกัน (โมเมนตัมรวมก่อนและหลังเป็นศูนย์)
  • หาความสัมพันธ์ระหว่างอัตราส่วนความเร็วกับอัตราส่วนมวล และการแบ่งพลังงานจลน์ระหว่างรถสองคัน
  • หามวลของรถที่ไม่ทราบค่าจากอัตราส่วนความเร็ว

อุปกรณ์ (เสมือนจริง)

  • รางลมยาว 120 cm มีสเกล · ตัวรับรถที่ปลายทั้งสองข้าง
  • รถ A (น้ำเงิน) ติดสปริงแผ่นอัดค้างด้วยสลัก · รถ B (ส้ม) หรือรถปริศนา X (ม่วง) · มวล 200 / 300 / 400 g
  • สปริงอัดได้ 3 ระดับ · การ์ดบังแสง 2.5 / 5.0 / 10.0 cm · โฟโตเกต 2 ตัว ต่อเครื่องจับเวลาจำได้เกตละ 2 ครั้ง

ขั้นตอน

  1. เลือกมวลรถ A และรถ B (เริ่ม 200 g ทั้งคู่) · ลากรถคู่ ไปไว้กลางราง · ลากเกต 1 ไว้ซ้ายรถ A และเกต 2 ไว้ขวารถ B ใกล้ ๆ
  2. กด ▶ ปลดสลัก — สปริงดันรถแยกไปคนละทาง
  3. กด 🔍 จอจับเวลา อ่าน t_A (เกต 1 ครั้งที่ 1) และ t_B (เกต 2 ครั้งที่ 1) · กรอกแล้วกด 📝 บันทึก
  4. เปลี่ยนมวลรถให้อัตราส่วน m_A/m_B ต่างกันอย่างน้อย 3 ค่า และลองเปลี่ยนระดับสปริง
  5. เปลี่ยนรถ B เป็น ❓ X ปลดสลักแล้วบันทึกอย่างน้อย 2 แถว หามวลของรถ X
⚠️ ความเร็วมีทิศ: รถ A ไปทางซ้ายจึงมีความเร็วเป็นลบ · ถ้ารวมโมเมนตัมโดยไม่คิดเครื่องหมายจะได้ค่าไม่เป็นศูนย์ · วางเกตไกลรถมาก แรงต้านเล็กน้อยของรางจะทำให้ความเร็วที่วัดลดลง

ตารางบันทึกผล (ตัวอย่างหัวตาราง)

m_A | m_B | t_A (ms) | t_B (ms) | v_A = −d/t_A | v_B = d/t_B | p_A | p_B | p_A + p_B | |v_B|/|v_A| | m_A/m_B | Ek_A | Ek_B | Ek รวม

คำถามท้ายการทดลอง

  1. โมเมนตัมรวมหลังดีดแยกเท่ากับเท่าใด เทียบกับก่อนปลดสลัก
  2. รถที่มีมวลมากกว่าเคลื่อนที่เร็วกว่าหรือช้ากว่า เป็นกี่เท่า
  3. พลังงานจลน์รวมขึ้นกับมวลรถหรือไม่ พลังงานนี้มาจากไหน
  4. รถคันใดได้พลังงานจลน์มากกว่า เพราะเหตุใด (ทั้งที่แรงที่สปริงดันรถทั้งสองเท่ากัน)
  5. ยกตัวอย่างการดีดตัวแยกในชีวิตจริง เช่น ปืนสะท้อนถอยหลัง จรวด นักสเกตผลักกัน

1. โมเมนตัมรวมเป็นศูนย์

ก่อนปลดสลัก รถทั้งสองอยู่นิ่ง โมเมนตัมรวมเป็นศูนย์ ขณะสปริงดัน แรงที่สปริงกระทำต่อรถ A และรถ B มีขนาดเท่ากัน ทิศตรงข้าม ในช่วงเวลาเดียวกัน (แรงภายในระบบ) โมเมนตัมรวมจึงยังคงเป็นศูนย์

0 = m_A v_A + m_B v_B
|v_B| / |v_A| = m_A / m_B (รถหนักเคลื่อนที่ช้ากว่า)

2. การแบ่งพลังงานจลน์

Ek รวม = ½ m_A v_A² + ½ m_B v_B² = พลังงานศักย์ยืดหยุ่นของสปริง (หักส่วนที่สูญเสียเล็กน้อย)
Ek_A / Ek รวม = m_B / (m_A + m_B) Ek_B / Ek รวม = m_A / (m_A + m_B)

แม้แรงดล (ขนาดของโมเมนตัม) ที่รถทั้งสองได้รับจะเท่ากัน แต่รถเบาได้ความเร็วมากกว่า จึงได้พลังงานจลน์มากกว่า เพราะ Ek = p²/2m

3. หามวลรถปริศนา X

m_X = m_A |v_A| / |v_B| = m_A · t_B / t_A (การ์ดกว้างเท่ากันจึงตัดกันไป)
💡 แบบจำลอง: สปริงแต่ละระดับปล่อยพลังงานคงที่ (แกว่ง ±2% ต่อครั้ง · สูญเสียเป็นความร้อน/เสียงราว 3%) · รางลมมีความหน่วงเหลือ 0.0004–0.0008 m/s² · มวลรถ X สุ่ม 250–550 g · เครื่องจับเวลาละเอียด 0.1 ms สัญญาณรบกวน ±0.2 ms
