วัตถุประสงค์

  • สังเกตลวดลายการแทรกสอดของแสงเลเซอร์ผ่านสลิตคู่และเกรตติง และลวดลายการเลี้ยวเบนผ่านสลิตเดี่ยว
  • หาความยาวคลื่นของแสงเลเซอร์จาก d sin θ = nλ (สลิตคู่ เกรตติง) และ a sin θ = nλ (แถบมืดของสลิตเดี่ยว)
  • ศึกษาผลของ d, L และ λ ต่อระยะห่างระหว่างแถบ

อุปกรณ์ (เสมือนจริง)

  • เลเซอร์ แดง 650 nm · เขียว 532 nm · ม่วง 405 nm · เลเซอร์ปริศนา (สุ่มความยาวคลื่น)
  • แผ่นสลิต: สลิตเดี่ยว a = 0.08 / 0.12 / 0.16 mm · สลิตคู่ d = 0.25 / 0.50 mm (กว้างช่องละ a = 0.08 mm) · เกรตติง 100 / 300 / 600 เส้น/mm
  • ฉากขาวกว้าง 120 cm มีสเกล mm (0 ที่แนวลำแสง) · ตลับเมตรวัดระยะสลิต–ฉาก L = 50–200 cm

การใช้งาน Simulation

  • 🎯 มองที่ฉาก กล้องหันเข้าฉากตรงตำแหน่งแว่นขยาย · มุมเฉียง / มุมข้าง ดูการจัดอุปกรณ์ (ลากหมุนได้)
  • ลวดลายบนฉากคำนวณทุกพิกเซลจาก I = I₀ (sin β/β)² × [ส่วนการแทรกสอด] — ความเข้มสูงสุดของแต่ละแถบลดลงตามการเลี้ยวเบนของแต่ละช่อง · ปรับ "ความสว่างที่แสดง" เพื่อดูแถบที่จาง
  • แว่นขยาย (แผนภาพล่าง): ลากหรือใช้ปุ่มเลื่อนไปที่แถบที่ต้องการ อ่านตำแหน่งจากสเกล mm บนฉาก
  • โหมดวัดเอง ไม่แสดงตำแหน่งแถบและ λ ของเลเซอร์ปริศนา · โหมดอัตโนมัติ แสดงตำแหน่งแถบ มุม และระยะแถบ

ตอนที่ A — สลิตคู่

  1. ใช้สลิตคู่ d = 0.25 mm เลเซอร์แดง L = 120 cm
  2. อ่านตำแหน่งแถบสว่างกลาง (n = 0) และแถบสว่างลำดับ n = 1, 2, 3, … ทางด้านเดียวกัน · x = ระยะจากแถบกลาง · กรอก n และ x แล้วกดบันทึก
  3. เพื่อลดความคลาดเคลื่อน วัดระยะระหว่างแถบลำดับ +n กับ −n แล้วหารสอง
  4. คำนวณ λ = d x / (nL) · เปลี่ยน L และ d แล้วทำซ้ำ · สังเกตระยะแถบ Δx = λL/d

ตอนที่ B — เกรตติง

  1. ใช้เกรตติง 300 เส้น/mm (d = 1/300 mm) · แถบสว่างอยู่ห่างกันมาก มุมใหญ่ ต้องใช้ sin θ ไม่ใช่ประมาณ
  2. อ่าน x ของจุดสว่างลำดับ n = 1, 2 · คำนวณ θ = tan⁻¹(x/L) และ λ = d sin θ / n
  3. เปรียบเทียบความคมของแถบสว่างของเกรตติงกับสลิตคู่
  4. เปลี่ยนเป็นแสงขาว (ใช้ได้กับเกรตติงเท่านั้น — แสงขาวจากหลอดไฟผ่านสลิตคู่หรือสลิตเดี่ยวจะไม่เห็นแถบการแทรกสอด เพราะแหล่งกำเนิดกว้างและไม่อาพันธ์) สังเกตสเปกตรัมแต่ละลำดับ (ม่วงใกล้กลาง แดงไกล) · แถบกลางเป็นสีขาว · สังเกตว่าลำดับที่ 2 และ 3 ซ้อนทับกัน · วัดตำแหน่งขอบม่วงและขอบแดงของลำดับที่ 1 แล้วคำนวณช่วงความยาวคลื่นของแสงขาว

ตอนที่ C — สลิตเดี่ยว (เปรียบเทียบ)

  1. สังเกตแถบสว่างกลางกว้างเป็นสองเท่าของแถบอื่น · วัด x ของแถบมืดลำดับ n · λ = a x / (nL)

คำถามท้ายการทดลอง

  1. เมื่อเพิ่ม L หรือลด d ระยะห่างระหว่างแถบสว่างเปลี่ยนอย่างไร?
  2. เลเซอร์สีใดให้แถบห่างกันมากที่สุด เพราะอะไร?
  3. ทำไมแถบสว่างของเกรตติงจึงคมกว่าและห่างกันมากกว่าของสลิตคู่?
  4. ทำไมแถบสว่างของสลิตคู่ที่อยู่ไกลจากกลางจึงจางลง และบางแถบหายไป?
  5. สำหรับเกรตติง เหตุใดสูตร x = nλL/d จึงให้ผลคลาดมาก?

1. การแทรกสอดจากสลิตคู่ (การทดลองของยัง)

แสงจากสองช่องเป็นแหล่งกำเนิดอาพันธ์ ที่จุดบนฉากทำมุม θ ความต่างระยะทางเดิน = d sin θ · ถ้าเท่ากับจำนวนเต็มเท่าของ λ เกิดการแทรกสอดแบบเสริม (แถบสว่าง) · ถ้าเท่ากับครึ่งจำนวนเต็มเท่า เกิดแบบหักล้าง (แถบมืด)

แถบสว่าง d sin θ = nλ แถบมืด d sin θ = (n − ½)λ
มุมเล็ก sin θ ≈ tan θ = x/L → x = nλL/d ระยะแถบ Δx = λL/d

2. การเลี้ยวเบนจากช่องแคบแต่ละช่อง และลวดลายรวม

แต่ละช่องกว้าง a ทำให้แสงเลี้ยวเบน ความเข้มลดลงตาม (sin β/β)² เมื่อ β = πa sin θ/λ · แถบมืดของสลิตเดี่ยวอยู่ที่ a sin θ = nλ · ลวดลายสลิตคู่ = ลวดลายการแทรกสอด cos²(πd sin θ/λ) คูณด้วยลวดลายการเลี้ยวเบน · ถ้าแถบสว่างของการแทรกสอดตรงกับแถบมืดของการเลี้ยวเบน แถบนั้นจะหายไป

I(θ) = I₀ (sin β/β)² · [sin(Nα)/(N sin α)]² α = πd sin θ/λ, β = πa sin θ/λ
สลิตคู่ N = 2 → cos² α เกรตติง N เส้นจำนวนมาก → แถบคมมาก

3. เกรตติง

เกรตติงมีช่องจำนวนมากห่างกัน d = 1/(จำนวนเส้นต่อหน่วยความยาว) · แถบสว่างอยู่ที่ d sin θ = nλ เหมือนสลิตคู่ แต่คมมากเพราะช่องจำนวนมากแทรกสอดพร้อมกัน · d เล็กมาก มุม θ จึงใหญ่ ต้องหา θ จาก tan θ = x/L แล้วใช้ sin θ · ลำดับสูงสุดที่เห็นได้ n ≤ d/λ

💡 ทำไมใช้แสงขาวกับเกรตติงได้ แต่สลิตคู่ไม่ได้? การแทรกสอดต้องใช้แสงอาพันธ์ · เลเซอร์ให้แสงอาพันธ์ · หลอดไฟเป็นแหล่งกำเนิดกว้าง แสงจากแต่ละจุดของไส้หลอดสร้างลวดลายที่เลื่อนตำแหน่งกัน รวมกันจนแถบของสลิตคู่ (ห่างกันเพียงไม่กี่มิลลิเมตร) กลืนหาย และแต่ละสีมีระยะแถบต่างกัน · ยังของเคยทำได้เพราะให้แสงผ่านรูเล็กมากก่อน (ได้แถบสีจาง ๆ ไม่กี่แถบ) · เกรตติงแยกแต่ละสีไปคนละมุมที่ห่างกันมาก (หลายเซนติเมตร) จึงเห็นสเปกตรัมชัดแม้ใช้หลอดไฟผ่านช่องแคบ
💡 ในการทดลองจริง จุดสว่างของเกรตติงมีขนาดเท่ากับลำแสงเลเซอร์ (ความกว้างเชิงมุมจริงเล็กกว่านั้นมาก) — simulation แสดงแบบเดียวกัน
