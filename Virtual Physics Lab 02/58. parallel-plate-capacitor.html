วัตถุประสงค์

  • หาความจุของตัวเก็บประจุแผ่นขนานจาก C = Q/V และศึกษาความสัมพันธ์ระหว่าง C กับระยะห่าง d และพื้นที่แผ่น A
  • หาค่าสภาพยอมของสุญญากาศ ε₀ จากความชันของกราฟ C กับ 1/d
  • สังเกตการเปลี่ยนแปลงความต่างศักย์เมื่อประจุคงที่ แล้วเปลี่ยน d หรือสอดฉนวน · หาค่าคงตัวไดอิเล็กทริก κ

อุปกรณ์ (เสมือนจริง)

  • แผ่นอะลูมิเนียมวงกลม 2 แผ่น (รัศมี 8.0 cm หรือ 12.5 cm) บนขาฉนวน · แผ่นขวาเลื่อนบนรางที่มีสเกล mm (0 = แผ่นแตะกัน)
  • แหล่งจ่ายไฟตรง 0–100 V · สวิตช์ 3 ตำแหน่ง · คูลอมบ์มิเตอร์ (ละเอียด 0.01 nC) · อิเล็กโทรมิเตอร์ (โวลต์มิเตอร์ความต้านทานขาเข้าสูงมาก ความจุขาเข้า 15 pF)
  • แผ่นฉนวนหนา 3.0 mm: อะคริลิก · แก้ว · แผ่นปริศนา (ไม่ทราบ κ)
⚠️ สายไฟและขั้วต่อมีความจุแฝงประมาณ 12 pF ต่อขนานกับตัวเก็บประจุเสมอ · ขอบแผ่นมีสนามไฟฟ้าล้นออก (fringing) ทำให้ความจุจริงมากกว่า ε₀A/d โดยเฉพาะเมื่อ d มาก · กราฟ C–1/d จึงไม่ผ่านจุดกำเนิดพอดี

การใช้งาน Simulation

  • สวิตช์: ① ต่อแหล่งจ่าย แผ่นมีแรงดันเท่าแหล่งจ่าย · ② แยกวงจร ประจุบนแผ่นคงที่ · ③ คายประจุผ่านคูลอมบ์มิเตอร์ มิเตอร์บอกประจุที่ไหลผ่าน (สะสมจนกว่าจะตั้งศูนย์)
  • โหมดวัดเอง: ไม่แสดงตัวเลขระยะ d และค่าจากแบบจำลอง อ่าน d จากแว่นขยายสเกล · โหมดอัตโนมัติ: แสดง C, Q, E, U, κ และภาพประจุ/สนามในช่องว่าง (κ ของแผ่นปริศนาแสดงหลังบันทึกผลที่ใช้แผ่นปริศนาในตาราง)
  • ↺ รีเซตค่า คายประจุ ตั้งศูนย์มิเตอร์ d = 4 mm แรงดัน 50 V รัศมี 12.5 cm ไม่มีฉนวน สวิตช์ ②

ตอนที่ A — ความจุกับระยะห่าง (หา ε₀)

  1. ไม่มีฉนวน รัศมี 12.5 cm ตั้งแหล่งจ่าย 50 V · ตั้ง d = 2.0 mm
  2. สวิตช์ ① (อัดประจุ) → ตั้งศูนย์คูลอมบ์มิเตอร์ → สวิตช์ ③ (คายประจุ) อ่าน Q · บันทึกตาราง A (d, V = 50, Q)
  3. ทำซ้ำที่ d = 3, 4, 5, 6, 8, 10, 12, 15, 20 mm · เขียนกราฟ C = Q/V กับ 1/d หาความชัน = ε₀A แล้วคำนวณ ε₀
  4. เปลี่ยนเป็นแผ่นรัศมี 8.0 cm ทำซ้ำ เปรียบเทียบความชันกับอัตราส่วนพื้นที่

ตอนที่ B — ประจุคงที่ (แยกวงจร)

  1. d = 3.0 mm สวิตช์ ① อัดประจุที่ 50 V → สวิตช์ ② (แยกวงจร) · อ่านอิเล็กโทรมิเตอร์
  2. ค่อย ๆ เพิ่ม d เป็น 4, 6, 8, 10, 15 mm อ่านแรงดัน บันทึกตาราง B · เขียนกราฟ V กับ d
  3. กลับมาที่ d = 3.0 mm แล้วสอดแผ่นฉนวน (อะคริลิก / แก้ว / ปริศนา) อ่านแรงดัน · V_อากาศ / V_ฉนวน ได้ค่าน้อยกว่า κ เพราะความจุแฝงของสายและมิเตอร์ต่อขนานอยู่ · หา κ ที่แม่นกว่าด้วยตาราง A: κ = (C_ฉนวน − C_แฝง) / (C_อากาศ − C_แฝง) ที่ d = 3.0 mm โดย C_แฝง ≈ จุดตัดแกนของกราฟ C–1/d

วิธีบันทึกผล

C = Q / V (1 nC / 1 V = 1 nF = 1000 pF)
C = ε₀A/d → ความชันของกราฟ C–1/d = ε₀A A = πR²
ประจุคงที่: V = Q/C ∝ d ฉนวนเต็มช่อง: C = κε₀A/d

คำถามท้ายการทดลอง

  1. เมื่อแยกวงจรแล้วดึงแผ่นให้ห่างขึ้น แรงดันเพิ่มขึ้น พลังงานที่สะสมเพิ่มขึ้นหรือลดลง พลังงานมาจากไหน
  2. ถ้าต่อกับแหล่งจ่ายไว้ตลอดแล้วดึงแผ่นให้ห่างขึ้น ประจุบนแผ่นเปลี่ยนอย่างไร
  3. ทำไมกราฟ C–1/d จึงมีจุดตัดแกน C ไม่เป็นศูนย์
  4. สอดฉนวนแล้วสนามไฟฟ้าในฉนวนลดลงเพราะอะไร (ใช้แนวคิดโพลาไรเซชัน)
  5. แผ่นปริศนามีค่า κ ประมาณเท่าใด น่าจะเป็นวัสดุอะไร

1. ตัวเก็บประจุและความจุ

ตัวเก็บประจุประกอบด้วยตัวนำสองชิ้นวางใกล้กันโดยมีฉนวนคั่น · เมื่อต่อกับความต่างศักย์ V แผ่นหนึ่งมีประจุ +Q อีกแผ่น −Q · ความจุ C คืออัตราส่วนของประจุต่อความต่างศักย์ หน่วยฟารัด (F = C/V)

C = Q / V พลังงานสะสม U = ½QV = ½CV² = Q²/2C

2. ตัวเก็บประจุแผ่นขนาน

สนามไฟฟ้าระหว่างแผ่นสม่ำเสมอ E = σ/ε₀ = Q/(ε₀A) · ความต่างศักย์ V = Ed = Qd/(ε₀A) จึงได้

C = ε₀A / d ε₀ = 8.85 × 10⁻¹² C²/(N·m²) = 8.85 pF/m
ตัวอย่าง: R = 12.5 cm, d = 2 mm → C = 217 pF

3. ฉนวนไดอิเล็กทริก

เมื่อสอดฉนวนระหว่างแผ่น โมเลกุลในฉนวนเกิดโพลาไรเซชัน มีประจุเหนี่ยวนำที่ผิวฉนวนหักล้างสนามบางส่วน สนามในฉนวนลดลงเหลือ E/κ ความจุจึงเพิ่มเป็น κ เท่า (ถ้าฉนวนเต็มช่อง)

C = κε₀A / d ฉนวนหนา t ไม่เต็มช่อง: C = ε₀A / (d − t + t/κ)

4. ประจุคงที่ กับ ความต่างศักย์คงที่

  • แยกวงจร (Q คงที่): ดึงแผ่นห่างขึ้น C ลด V = Q/C เพิ่มตาม d · U = Q²/2C เพิ่ม — พลังงานมาจากงานที่ใช้ดึงแผ่น (แผ่นดูดกัน)
  • ต่อแหล่งจ่าย (V คงที่): ดึงแผ่นห่างขึ้น C ลด Q = CV ลด ประจุไหลกลับเข้าแหล่งจ่าย
💡 แบบจำลองใน simulation: C_แผ่น = ε₀πR²/d_eff + ε₀R[ln(16πR/d) − 1] (สูตรของเคิร์ชฮอฟฟ์สำหรับจานกลมบาง รวมผลของขอบ) · d_eff = d − t + t/κ เมื่อมีฉนวน · ความจุแฝงของสาย 12 pF · อิเล็กโทรมิเตอร์ 15 pF
อ้างอิง: หนังสือเรียนรายวิชาเพิ่มเติมฟิสิกส์ (สสวท.) บทไฟฟ้าสถิต — ตัวเก็บประจุ ความจุ พลังงานในตัวเก็บประจุ · เทียบเคียงการทดลอง Parallel-plate capacitor / determination of ε₀ ใน A-level, IB และปฏิบัติการฟิสิกส์มหาวิทยาลัย
