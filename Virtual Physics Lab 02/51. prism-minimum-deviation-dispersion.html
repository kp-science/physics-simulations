วัตถุประสงค์

  • ศึกษาความสัมพันธ์ระหว่างมุมตกกระทบ i กับมุมเบี่ยงเบน δ ของแสงที่ผ่านปริซึม
  • หามุมเบี่ยงเบนน้อยที่สุด δmin และคำนวณดรรชนีหักเหของปริซึม n = sin((A+δmin)/2) / sin(A/2)
  • สังเกตการกระจายแสง — แสงแต่ละสีมีดรรชนีหักเหต่างกัน จึงเบี่ยงเบนต่างกัน

อุปกรณ์ (เสมือนจริง)

  • ปริซึมสามเหลี่ยมด้านเท่า มุมยอด A = 60° ด้านยาว 6 cm สูง 2.5 cm · วัสดุ: แก้วคราวน์ แก้วฟลินต์ อะคริลิก และวัสดุปริศนา
  • แท่นหมุนมีเข็มชี้บนสเกลมุมตกกระทบ i (หมุนรอบจุดกึ่งกลางผิวรับแสง จุดตกกระทบจึงอยู่ที่เดิม)
  • แหล่งกำเนิดแสง: เลเซอร์แดง 650 nm · เลเซอร์เขียว 532 nm · เลเซอร์ม่วง 405 nm · แสงขาว
  • ดินสอต่อแนวรังสี และโปรแทรกเตอร์วางที่จุดตัดของแนวรังสีตกกระทบกับแนวรังสีออก

การใช้งาน Simulation

  • ⬇ มุมบน (ค่าเริ่มต้น) · มุมเฉียง / มุมต่ำ หมุนมุมมองได้ — มองผ่านปริซึมเห็นกระดาษและเส้นรังสีด้านหลังหักเหจริง
  • หมุนปริซึม: ลากรอบปริซึมในภาพ 3D หรือแผนภาพ 2D · สไลเดอร์ · ปุ่ม ±1° / ±0.1°
  • เส้นแสงบนกระดาษคำนวณด้วยกฎของสเนลล์ทุกผิว ความสว่างตามสมการเฟรเนล (มีแสงสะท้อนจาง ๆ ที่ผิวรับแสง และสะท้อนกลับหมดเมื่อ i น้อยเกินไป)
  • ดรรชนีหักเหขึ้นกับความยาวคลื่นตามสูตรของโคชี n(λ) = Ac + Bc/λ² — แสงม่วงหักเหมากกว่าแสงแดง
  • แว่นขยาย 2 ช่องในแผนภาพ 2D: เข็มชี้บนแท่นหมุน (อ่าน i) และจุดที่รังสีออกตัดวงโปรแทรกเตอร์ (อ่าน δ)
  • 🧭 ตอนนี้ต้องทำอะไร บอกขั้นถัดไปตามสิ่งที่บันทึกแล้วของแสงและวัสดุที่เลือก (ไม่บอกมุมหรือ n ในโหมดวัดเอง)
  • โหมดวัดเอง ไม่แสดงค่ามุมและ n · โหมดอัตโนมัติ แสดง i, r₁, r₂, e, δ, δmin และกราฟทฤษฎี
  • ↺ รีเซตค่า หมุนปริซึมกลับ i = 40° มุมมองเริ่มต้น (ตารางยังอยู่)

ตอนที่ A — หามุมเบี่ยงเบนน้อยที่สุด

  1. เลือกเลเซอร์แดง หมุนปริซึมให้ i ประมาณ 30° อ่าน i จากเข็มชี้ และ δ จากโปรแทรกเตอร์ กรอกแล้วกด 📝 บันทึก
  2. เพิ่ม i ครั้งละประมาณ 5° จนถึง 80° บันทึกทุกครั้ง · สังเกตว่าเมื่อหมุนไปทางเดียว รังสีออกเคลื่อนเข้าหาแนวเดิม หยุด แล้วย้อนกลับ
  3. เขียนกราฟ δ กับ i หาจุดต่ำสุด · ปรับละเอียดรอบจุดนั้นจนรังสีออก "หยุดแล้วเริ่มย้อนกลับ" อ่าน δ แล้วกด 📍 บันทึก δ เป็น δmin
  4. คำนวณ n = sin((A+δmin)/2) / sin(A/2) โดย A = 60°

ตอนที่ B — การกระจายแสง

  1. หา δmin ของเลเซอร์เขียวและเลเซอร์ม่วง เปรียบเทียบค่า n ของแต่ละสี
  2. เปลี่ยนเป็นแสงขาว สังเกตสเปกตรัมบนกระดาษ สีใดเบี่ยงเบนมากที่สุด · ลองแก้วฟลินต์ แถบสเปกตรัมกว้างขึ้นหรือแคบลง?

คำถามท้ายการทดลอง

  1. กราฟ δ กับ i มีลักษณะอย่างไร ที่มุมเบี่ยงเบนน้อยที่สุดรังสีในปริซึมมีทิศอย่างไรเทียบกับฐาน?
  2. เมื่อ i น้อยมาก เหตุใดจึงไม่มีรังสีออกจากผิวที่สองของปริซึม?
  3. แสงสีใดมีดรรชนีหักเหมากที่สุดในแก้ว · อัตราเร็วของแสงสีนั้นในแก้วมากหรือน้อย?
  4. ทำไมแก้วฟลินต์จึงให้แถบสเปกตรัมกว้างกว่าแก้วคราวน์?
  5. สาเหตุความคลาดเคลื่อนในการหา δmin มีอะไรบ้าง?

1. การหักเหผ่านปริซึม

แสงหักเหสองครั้ง: เข้าที่ผิวแรก (i → r₁) และออกที่ผิวที่สอง (r₂ → e) · รังสีเบนเข้าหาฐานของปริซึม · มุมเบี่ยงเบน δ คือมุมระหว่างแนวรังสีตกกระทบเดิมกับรังสีที่ออก

sin i = n sin r₁ sin e = n sin r₂
A = r₁ + r₂ δ = i + e − A

2. มุมเบี่ยงเบนน้อยที่สุด

เมื่อเพิ่ม i มุมเบี่ยงเบนลดลงถึงค่าต่ำสุดแล้วเพิ่มขึ้น · ที่ค่าต่ำสุดรังสีผ่านปริซึมแบบสมมาตร i = e และ r₁ = r₂ = A/2 (รังสีในปริซึมขนานกับฐาน) จึงได้

i = (A + δmin)/2 r₁ = A/2
n = sin((A + δmin)/2) / sin(A/2)

ข้อดีของวิธีนี้: ที่ใกล้จุดต่ำสุด δ แทบไม่เปลี่ยนเมื่อ i เปลี่ยนเล็กน้อย การอ่าน δmin จึงคลาดน้อย

3. การกระจายแสง

ดรรชนีหักเหของแก้วขึ้นกับความยาวคลื่น (สูตรของโคชี n = Ac + Bc/λ²) แสงความยาวคลื่นสั้น (ม่วง) มี n มากกว่าจึงหักเหและเบี่ยงเบนมากกว่าแสงแดง แสงขาวจึงแยกเป็นสเปกตรัม ม่วง คราม น้ำเงิน เขียว เหลือง แสด แดง · แก้วฟลินต์มี Bc มากกว่าจึงกระจายแสงมากกว่า

วัสดุn (แดง 650)n (เหลือง 589)n (ม่วง 405)
อ้างอิง: หนังสือเรียนฟิสิกส์ ม.5 (สสวท.) บทแสงเชิงรังสี — การหักเหผ่านปริซึม มุมเบี่ยงเบนน้อยที่สุด และการกระจายแสง
