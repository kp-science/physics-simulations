วัตถุประสงค์

  • หาความจุสมมูลของตัวเก็บประจุที่ต่อแบบอนุกรม ขนาน และผสม แล้วเปรียบเทียบกับค่าที่คำนวณได้
  • ศึกษาความต่างศักย์และประจุของตัวเก็บประจุแต่ละตัวในการต่อแบบต่าง ๆ
  • ศึกษาการแบ่งประจุเมื่อนำตัวเก็บประจุที่มีประจุไปต่อกับตัวที่ไม่มีประจุ และพลังงานที่หายไป

อุปกรณ์ (เสมือนจริง)

  • ตัวเก็บประจุชนิดฟิล์ม 1.0, 2.2, 3.3, 4.7, 10 μF (คลาดเคลื่อน ±5% ค่าจริงแต่ละตัวไม่เท่าค่าระบุ) · แผ่นต่อวงจรมีขั้ว A และ B
  • ❓ ตัวเก็บประจุปริศนา Cx — ไม่ทราบค่า (มากกว่าช่วงวัดของมิเตอร์ ถอดวัดตรง ๆ จะขึ้น OL)
  • แหล่งจ่ายไฟตรง 1–12 V · สวิตช์ 3 ตำแหน่ง ① อัดประจุ ② แยกวงจร ③ คายประจุ (ลัดวงจร A–B) · สวิตช์ S₂ (เฉพาะการแบ่งประจุ)
  • โวลต์มิเตอร์ความต้านทานขาเข้าสูงมาก (ไม่ดึงประจุ) ละเอียด 0.01 V · มิเตอร์วัดความจุ ละเอียด 0.01 μF ช่วงวัดสูงสุด 50 μF

การใช้งาน Simulation

  • 🧭 ทำตามขั้นตอนนี้ (กรอบสีเขียวด้านบน): เลือกตอน A / B / C / D แล้วทำตามขั้นที่แสดง · ปุ่มที่ต้องกดจะกระพริบสีเหลือง · ปุ่ม 👉 ช่วยทำขั้นนั้นให้ · ขั้นที่ทำแล้วขึ้น ✓ อัตโนมัติ
  • 📝 จดค่าแรงดัน / 📝 จดค่าความจุ: เขียนค่าบนจอมิเตอร์ลงช่องที่ตรงกันในตาราง A, B, C ให้เอง ไม่ต้องพิมพ์
  • เลือกรูปแบบการต่อและค่าตัวเก็บประจุแต่ละช่อง · แตะตัวเก็บประจุในแผนภาพหรือภาพ 3D เพื่อย้ายสายวัดโวลต์มิเตอร์
  • มิเตอร์วัดความจุวัดได้เมื่อสวิตช์อยู่ที่ ② และวงจรไม่มีประจุ · ปุ่ม "C₁ (ถอดวัด)" = ถอดตัวเก็บประจุออกมาวัดทีละตัว
  • โหมดวัดเอง: ไม่แสดงประจุและแรงดันของแต่ละตัว อ่านจากเครื่องวัดเอง · โหมดอัตโนมัติ: แสดงตาราง C, V, Q, U ของทุกตัวและเติมค่าลงตารางบันทึกให้ (รวมค่าจริงของ Cx)
  • ↺ รีเซตค่า (ปุ่มเขียวบนภาพ 3D หรือในแผงควบคุม) คายประจุ สวิตช์ ② แรงดัน 9.0 V

ตอนที่ A — ความจุสมมูล

  1. เลือก "อนุกรม 2 ตัว" C₁ = 2.2 μF, C₂ = 4.7 μF · วัดความจุทีละตัว (ถอดวัด) แล้วกด 📝 จดค่าความจุ
  2. วัดความจุระหว่าง A–B แล้วจดค่า · ตาราง A คำนวณค่าจากสูตรโดยใช้ C ที่วัดได้ให้เปรียบเทียบ
  3. ทำซ้ำกับ ขนาน 2 ตัว · อนุกรม 3 ตัว · ขนาน 3 ตัว · และแบบผสมทั้งสองแบบ

ตอนที่ B — แรงดันและประจุ

  1. อนุกรม 2 ตัว · แหล่งจ่าย 9.0 V · สวิตช์ ① อัดประจุ · วัดและจดค่า V_AB, V₁, V₂ ลงตาราง B
  2. สังเกตว่า V₁ + V₂ = V_AB และ Q₁ = C₁V₁ เท่ากับ Q₂ = C₂V₂ หรือไม่ · ตัวที่ความจุน้อยได้แรงดันมากหรือน้อย
  3. ทำซ้ำกับการต่อขนาน: V เท่ากันทุกตัว Q รวม = Q₁ + Q₂ · และแบบผสม

ตอนที่ C — การแบ่งประจุ

  1. เลือก "แบ่งประจุ" · S₂ เปิด · สวิตช์ ① อัดประจุ C₁ ที่ 9.0 V · สวิตช์ ② แยกวงจร · วัดและจดค่า V₁
  2. ปิด S₂ (ต่อ C₁ กับ C₂ ที่ไม่มีประจุ) · วัดและจดค่า V₁, V₂ ใหม่ · เปรียบเทียบกับ V = C₁V₀/(C₁ + C₂)
  3. คำนวณพลังงานก่อนและหลัง พลังงานหายไปเท่าใด ไปอยู่ที่ไหน

ตอนที่ D — หาความจุของตัวเก็บประจุปริศนา Cx

  1. ถอดวัด Cx ตรง ๆ มิเตอร์ขึ้น OL (เกิน 50 μF) · ต่อ "อนุกรม 2" ให้ C₁ = 10 μF และ C₂ = ❓ Cx · วัด C₁ (ถอดวัด) และ C_AB แล้วจดค่า
  2. คำนวณ Cx = C₁·C_AB / (C₁ − C_AB) (ตาราง A แก้สมการให้) · ตรวจซ้ำด้วยตอน B: อัดประจุ จด V₁ และ V₂ อนุกรมมีประจุเท่ากัน → Cx = C₁V₁/V₂ · หรือตอน C (C₂ = Cx): Cx = C₁(V₀ − V)/V

วิธีบันทึกผล

อนุกรม: 1/C = 1/C₁ + 1/C₂ + … Q เท่ากันทุกตัว V = V₁ + V₂ + …
ขนาน: C = C₁ + C₂ + … V เท่ากันทุกตัว Q = Q₁ + Q₂ + …
Q = CV U = ½CV² แบ่งประจุ: V = C₁V₀ / (C₁ + C₂)
หา Cx: อนุกรม Cx = C₁C_AB/(C₁ − C_AB) · อนุกรมอัดประจุ Cx = C₁V₁/V_x · แบ่งประจุ Cx = C₁(V₀ − V)/V

คำถามท้ายการทดลอง

  1. ความจุสมมูลของการต่ออนุกรมน้อยกว่าตัวที่น้อยที่สุดเสมอหรือไม่ เพราะอะไร
  2. ทำไมตัวเก็บประจุที่ต่ออนุกรมจึงมีประจุเท่ากัน (คิดถึงแผ่นโลหะที่อยู่ระหว่างตัวเก็บประจุสองตัว)
  3. ถ้าต้องการตัวเก็บประจุที่ทนแรงดันสูงขึ้นจากตัวที่ทนได้ 6 V ควรต่อแบบใด
  4. ในการแบ่งประจุ ประจุรวมคงที่แต่พลังงานลดลง พลังงานที่หายไปกลายเป็นอะไร
  5. Cx ที่หาได้จากสามวิธีใกล้เคียงกันหรือไม่ วิธีใดคลาดเคลื่อนน้อยที่สุด เพราะอะไร (ลองคิดว่า C₁ − C_AB มีค่าน้อยมาก)

1. การต่อแบบอนุกรม

เมื่ออัดประจุ แผ่นซ้ายสุดได้ +Q แผ่นขวาสุดได้ −Q · แผ่นที่อยู่ระหว่างตัวเก็บประจุต่อถึงกันเป็นตัวนำโดดเดี่ยว ประจุสุทธิเป็นศูนย์ จึงเกิดการเหนี่ยวนำ −Q และ +Q ทุกตัวจึงมีประจุเท่ากัน · ความต่างศักย์รวมเท่ากับผลบวกของแต่ละตัว

V = Q/C₁ + Q/C₂ + Q/C₃ → 1/C = 1/C₁ + 1/C₂ + 1/C₃ สองตัว: C = C₁C₂/(C₁ + C₂)

2. การต่อแบบขนาน

ทุกตัวต่อคร่อมจุด A และ B เดียวกัน จึงมีความต่างศักย์เท่ากัน · ประจุรวมเท่ากับผลบวกของประจุแต่ละตัว เหมือนเพิ่มพื้นที่แผ่น

Q = C₁V + C₂V + C₃V → C = C₁ + C₂ + C₃

3. การต่อแบบผสม

ลดวงจรทีละส่วน: รวมตัวที่ขนานกันก่อน แล้วรวมกับตัวที่อนุกรม · เช่น C₁ อนุกรมกับ (C₂ ∥ C₃): C = C₁(C₂ + C₃)/(C₁ + C₂ + C₃)

4. การแบ่งประจุและพลังงานที่หายไป

C₁ มีประจุ Q₀ = C₁V₀ ต่อขนานกับ C₂ ที่ไม่มีประจุ · ประจุรวมคงที่ แรงดันสุดท้ายเท่ากันทั้งสองตัว

V = C₁V₀/(C₁ + C₂) U_หลัง/U_ก่อน = C₁/(C₁ + C₂)
💡 พลังงานที่หายไปกลายเป็นความร้อนในสายไฟและการแผ่คลื่นแม่เหล็กไฟฟ้าขณะประจุไหล (เกิดประกายไฟเล็ก ๆ ที่หน้าสัมผัสสวิตช์) · ไม่ขึ้นกับความต้านทานของสาย · simulation แก้ระบบสมการของทุกโหนด: โหนดที่ต่อแหล่งจ่ายมีศักย์คงที่ โหนดโดดเดี่ยวรักษาประจุสุทธิไว้ (การอนุรักษ์ประจุ)
