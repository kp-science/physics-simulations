วัตถุประสงค์

  • ศึกษาการหักเหของแสงเมื่อผ่านตัวกลางหลายชั้นที่มีผิวรอยต่อขนานกัน
  • ตรวจสอบว่า n sin θ มีค่าคงตัวในทุกชั้น (กฎของสเนลล์ใช้ต่อเนื่องได้ทีละรอยต่อ)
  • หาดรรชนีหักเหของของเหลวปริศนา และศึกษาผลของความหนาแต่ละชั้นต่อตำแหน่งจุดแสงที่ก้นถัง
  • สังเกตการสะท้อนกลับหมดเมื่อแสงเข้าทางผนังข้างถัง

อุปกรณ์ (เสมือนจริง)

  • ถังแก้วใส กว้าง 30 cm ลึก 12 cm สูง 24 cm
  • ของเหลว 9 ชนิด + ของเหลวปริศนา ซ้อนได้ 1–5 ชั้น ชั้นละ 0.5–8 cm (รวมไม่เกิน 20 cm) · เติมนมเล็กน้อยเพื่อให้เห็นลำแสง
  • เลเซอร์สีแดง ตั้งได้ 2 แบบ: ส่องจากด้านบน (ตกกระทบผิวบนที่ตำแหน่งคงที่) หรือ ส่องผ่านผนังข้าง (ปรับความสูงจุดเข้าและมุมเงยได้)
  • แผ่นกราฟสีขาว (ขีดละ 1 mm) ตั้งชิดผนังหลังด้านในถัง ลำแสงเลียดผิวแผ่นจึงเห็นเป็นเส้นแสงบนกราฟ · ตัวเลข x (cm) นับจากเส้น 0 ที่อยู่ใต้จุดตกกระทบพอดี
  • แว่นขยาย มองตั้งฉากกับแผ่นกราฟ (ไม่มีพาราแลกซ์) อ่าน x ได้ละเอียดถึงครึ่งมิลลิเมตร · ฐานเลเซอร์มีสเกลมุม

การใช้งาน Simulation

  • จำนวนชั้น 1–5 · แต่ละชั้นเลือกชนิดของเหลวและความหนาได้ (สไลเดอร์/ช่องตัวเลข)
  • ปรับมุมเลเซอร์ด้วยสไลเดอร์ · ปุ่ม ±1° / ±0.1° ปรับละเอียด · ลากในภาพ 3D เพื่อหมุนมุมมอง · คลิกที่จุดบนแผ่นกราฟเพื่อย้ายแว่นขยายไปที่จุดนั้น
  • ⇅ เรียงตามความหนาแน่น จัดชั้นให้ของเหลวหนาแน่นมากอยู่ล่าง (แบบที่เกิดจริง) · ถ้าเรียงผิดหรือของเหลวผสมกันได้ จะมีคำเตือน (ยังทดลองต่อได้ ให้คิดว่ามีแผ่นฟิล์มใสบางมากกั้นแต่ละชั้น)
  • แสงสะท้อนบางส่วน แสดงแสงที่สะท้อนที่รอยต่อทุกชั้นตามสมการเฟรเนล (จางมากเมื่อ n ใกล้กัน)
  • โหมดวัดเอง ต้องอ่าน x จากแผ่นกราฟเองทุกจุด · ไม่แสดง n ของของเหลวปริศนา · โหมดอัตโนมัติ เติมค่า x จริงในใบบันทึกให้ และกวาดมุมเลเซอร์ได้

ตอนที่ A — n sin θ คงตัวทุกชั้น

  1. ใช้เลเซอร์จากด้านบน ซ้อนของเหลว 3 ชั้น (เช่น น้ำมันพืช / น้ำ / คาร์บอนไดซัลไฟด์) ตั้งมุมตกกระทบ θ₀ ประมาณ 40°
  2. ใช้แว่นขยายอ่านตำแหน่ง x ที่ลำแสงตัดผิวบน (P0) รอยต่อแต่ละชั้น (P1, P2, …) และก้นถัง บนแผ่นกราฟ กรอกลงใบบันทึก (กด ◀ ▶ ที่แว่นขยายเพื่อเลื่อนไปจุดถัดไป)
  3. ในแต่ละชั้น ลำแสงเลื่อนไปทางข้าง Δx = xล่าง − xบน ขณะลงไปลึก d จึงได้ tan θ = Δx / d · ใบบันทึกคำนวณ θ และ n sin θ ให้ — เทียบกับ sin θ₀ (อากาศ n = 1) แล้วกด 📌 บันทึกชุดข้อมูลนี้
  4. เปลี่ยน θ₀ เป็น 20° และ 60° แล้วทำซ้ำ
  5. สลับลำดับชั้น (หรือเพิ่ม/ลดชั้น) โดยให้ชั้นล่างสุดเป็นของเหลวเดิม — มุมในชั้นล่างสุดเปลี่ยนหรือไม่?

ตอนที่ B — ของเหลวปริศนา

  1. เปลี่ยนชั้นใดชั้นหนึ่งเป็น ❓ ของเหลวปริศนา อ่าน x ที่ขอบบนและล่างของชั้นนั้น หา θ จาก tan θ = Δx/d
  2. คำนวณ n = sin θ₀ / sin θ · กด 📌 แล้วตารางจะเฉลยค่าจริง · ทำซ้ำหลายมุมแล้วหาค่าเฉลี่ย

ตอนที่ C — ความหนาของชั้นกับตำแหน่งจุดแสง

  1. ระยะที่ลำแสงเลื่อนไปทั้งหมดเมื่อถึงก้นถัง X = xก้นถัง − xP0 (อยู่ในชุดข้อมูลที่บันทึก)
  2. เปลี่ยนความหนาของชั้นใดชั้นหนึ่ง 3–4 ค่า อ่านและบันทึกใหม่ทุกครั้ง · เทียบ X กับ d₁ tan θ₁ + d₂ tan θ₂ + … (คำนวณจาก n ของแต่ละชั้น)

ตอนที่ D — แสงเข้าทางผนังข้างและการสะท้อนกลับหมด

  1. กด ➡ ผ่านผนังข้าง ใช้ของเหลวชั้นเดียว (น้ำ) ให้ลำแสงเฉียงขึ้นไปกระทบผิวบน
  2. เพิ่มมุมเงย α ทีละน้อย (±0.1°) อ่าน α จากสเกลฐานเลเซอร์ตอนที่แสงเริ่มทะลุผิวบนออกสู่อากาศ กด 📍 บันทึก α → n = √(1 + sin² α) · ทำกับเอทานอลและ ❓ ปริศนา
  3. เปลี่ยนเป็นกลีเซอรีนหรือคาร์บอนไดซัลไฟด์ — ยังหามุมนั้นได้หรือไม่? (ดูทฤษฎีข้อ 3)
  4. ซ้อนน้ำไว้บนคาร์บอนไดซัลไฟด์ ยิงแสงเข้าชั้นล่าง สังเกตการสะท้อนกลับหมดที่รอยต่อระหว่างชั้น
💡 เทียบกับ Lab 33B (ปักหมุดแท่งแก้ว) · Lab 48 (ความลึกปรากฏ) · Lab 49 (มุมวิกฤต) — ผนังแก้วบางของถังถือว่าไม่ทำให้ทิศของลำแสงเปลี่ยน (แผ่นขนานบางมาก)

คำถามท้ายการทดลอง

  1. ค่า n sin θ ในแต่ละชั้นเท่ากันหรือไม่ เท่ากับปริมาณใด?
  2. มุมของลำแสงในชั้นล่างสุดขึ้นกับชั้นที่อยู่ข้างบนหรือไม่ เพราะอะไร?
  3. เมื่อแสงเข้าทางผิวบนจากอากาศ เกิดการสะท้อนกลับหมดที่รอยต่อชั้นใด ๆ ได้หรือไม่ อธิบายด้วย n sin θ
  4. เมื่อแสงเข้าทางผนังข้าง ทำไมจึงสะท้อนกลับหมดที่ผิวบนได้ง่าย ของเหลวที่มี n ≥ √2 ต่างจากน้ำอย่างไร?
  5. ถ้าเพิ่มความหนาเฉพาะชั้นที่มี n มาก ตำแหน่ง X เปลี่ยนมากหรือน้อยกว่าเพิ่มชั้นที่มี n น้อย เพราะอะไร?
  6. ของเหลวคู่ใดในการทดลองที่ซ้อนกันได้จริงโดยไม่ผสมกัน และต้องวางชั้นใดไว้บน?

1. กฎของสเนลล์ผ่านหลายรอยต่อ

ที่รอยต่อแต่ละคู่ใช้กฎของสเนลล์ n₁ sin θ₁ = n₂ sin θ₂ · เมื่อผิวรอยต่อทุกชั้นขนานกัน เส้นแนวฉากของทุกรอยต่อเป็นเส้นดิ่งเดียวกัน มุมหักเหออกจากชั้นหนึ่งจึงเป็นมุมตกกระทบของชั้นถัดไปพอดี ต่อกันเป็นสาย:

n₀ sin θ₀ = n₁ sin θ₁ = n₂ sin θ₂ = … = nₖ sin θₖ = ค่าคงตัว
แสงเข้าจากอากาศ (n₀ = 1): nₖ sin θₖ = sin θ₀

ผลที่ตามมา: มุมในชั้นใด ๆ ขึ้นกับดรรชนีหักเหของชั้นนั้นกับมุมเริ่มต้นเท่านั้น ไม่ขึ้นกับว่าข้างบนมีกี่ชั้นหรือเป็นอะไร · ชั้นที่ n มากลำแสงเบนเข้าหาเส้นแนวฉากมาก ชั้นที่ n น้อยเบนออก

2. ตำแหน่งจุดแสงที่ก้นถัง

ในชั้นที่ i ความหนา dᵢ ลำแสงเคลื่อนที่ไปทางข้าง dᵢ tan θᵢ · ระยะรวมที่ก้นถัง (วัดจากแนวดิ่งใต้จุดตกกระทบ)

X = d₁ tan θ₁ + d₂ tan θ₂ + … + dₖ tan θₖ โดย sin θᵢ = sin θ₀ / nᵢ

ความลึกปรากฏเมื่อมองตรงลงมา (มุมเล็ก) ก็รวมแบบเดียวกัน: ลึกปรากฏ = d₁/n₁ + d₂/n₂ + … (เทียบ Lab 48)

3. แสงเข้าทางผนังข้างและการสะท้อนกลับหมด

ถ้าแสงตกกระทบผิวบนจากอากาศ ค่าคงตัว n sin θ = sin θ₀ < 1 ซึ่งน้อยกว่า n ของของเหลวทุกชนิด → ไม่มีทางสะท้อนกลับหมดที่รอยต่อใดเลย · แต่ถ้าแสงเข้าทางผนังข้าง (ผนังตั้งฉาก) ด้วยมุมเงย α จากแนวระดับ ในชั้นที่แสงเข้า (ดรรชนี nₑ):

ค่าคงตัว K = nₑ sin θₑ = √(nₑ² − sin² α)
แสงผ่านเข้าชั้น j ได้เมื่อ K < nⱼ · ออกผิวบนสู่อากาศได้เมื่อ K < 1

สำหรับน้ำ (n = 1.333) แสงออกผิวบนได้เฉพาะเมื่อ sin² α > n² − 1 หรือ α > 61.8° · ของเหลวที่มี n ≥ √2 ≈ 1.414 (กลีเซอรีน น้ำมันพืช CS₂) สะท้อนกลับหมดที่ผิวบนทุกมุม — เป็นเหตุผลที่มองผ่านผนังตู้ปลาขึ้นไปเห็นผิวน้ำเหมือนกระจกเงา

4. ดรรชนีหักเหและความหนาแน่นของของเหลว

ของเหลวn (589 nm)ρ (g/cm³)ผสมกับน้ำ
ของเหลวซ้อนเป็นชั้นได้จริงเมื่อไม่ผสมกันและชั้นบนมีความหนาแน่นน้อยกว่า เช่น น้ำมันพืชบนน้ำ · น้ำบนคาร์บอนไดซัลไฟด์ · ดรรชนีหักเหไม่ได้ขึ้นกับความหนาแน่นโดยตรง (เอทานอลเบากว่าน้ำแต่ n มากกว่า)
อ้างอิง: หนังสือเรียนฟิสิกส์ ม.5 (สสวท.) บทแสงเชิงรังสี — การหักเหของแสง กฎของสเนลล์ มุมวิกฤต และการสะท้อนกลับหมด
