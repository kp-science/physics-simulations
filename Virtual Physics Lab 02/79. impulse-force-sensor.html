วัตถุประสงค์

  • หาการดลจากพื้นที่ใต้กราฟแรง–เวลา และเปรียบเทียบกับโมเมนตัมที่เปลี่ยนไป (J = Δp)
  • ศึกษาผลของช่วงเวลาชนต่อแรงสูงสุด เมื่อโมเมนตัมที่เปลี่ยนไปใกล้เคียงกัน (หลักของถุงลมนิรภัยและเบาะรองรับ)
  • เปรียบเทียบการชนที่วัตถุเด้งกลับกับการชนที่วัตถุหยุดนิ่ง และหามวลรถที่ไม่ทราบค่าจากการดล

อุปกรณ์ (เสมือนจริง)

  • รางลมยาว 120 cm มีสเกล · เครื่องยิงสปริงที่ปลายซ้าย (อัด 1.0 / 1.5 / 2.0 cm)
  • รถเลื่อน 200 / 300 / 400 g และรถปริศนา X · ติดการ์ดบังแสง 2.5 / 5.0 / 10.0 cm
  • กันชนหน้ารถ 3 แบบ: 🔩 สปริงแข็ง · 🌀 สปริงนิ่ม · 🟤 ดินน้ำมัน
  • เซนเซอร์แรงยึดที่ปลายรางขวา ต่อกับเครื่องบันทึกข้อมูล แสดงกราฟแรง–เวลา (บันทึก 1000 ครั้ง/วินาที) บนจอในฉาก
  • โฟโตเกต 1 ตัว ต่อเครื่องจับเวลา จำได้ 2 ครั้ง (ขาไปและขากลับ)

การอ่านกราฟแรง–เวลาบนจอ

  • กด 📈 จอกราฟ เพื่อซูมไปที่จอ · แกนนอน ช่องละ 10 ms (200 ms เต็มจอ) · แกนตั้งปรับเต็มสเกลอัตโนมัติ 2 / 5 / 10 / 20 N และช่องละ 1/10 ของเต็มสเกล (ดูมุมจอ)
  • F_max = ความสูงของยอดกราฟ · Δt = ความกว้างของยอดกราฟ ตั้งแต่แรงเริ่มขึ้นจนกลับลงถึงศูนย์
  • การดล J = พื้นที่ใต้กราฟ: นับช่อง (ช่องเต็ม + ครึ่งช่อง) × พื้นที่ 1 ช่อง (N × s) · หรือกด ∫ พื้นที่ ให้ซอฟต์แวร์ของเครื่องบันทึกข้อมูลคำนวณ (แนะนำให้นับเองก่อนแล้วค่อยเปิดตรวจ)

ขั้นตอน

  1. เลือกรถ 200 g กันชน 🔩 สปริงแข็ง ลากโฟโตเกตไปวางใกล้เซนเซอร์แรง
  2. กด ▶ ยิงรถ — รถผ่านเกต ชนเซนเซอร์ แล้วเด้งกลับผ่านเกตอีกครั้ง
  3. อ่าน t₁ (ครั้งที่ 1) และ t₂ (ครั้งที่ 2) · อ่าน F_max, Δt และ J จากกราฟ · กรอกแล้วกด 📝 บันทึก
  4. ทำซ้ำกับ 🌀 สปริงนิ่ม และ 🟤 ดินน้ำมัน (ดินน้ำมันไม่เด้ง ไม่ต้องกรอก t₂) · เปลี่ยนมวลรถหรือระยะอัดสปริงเพิ่ม
  5. เปลี่ยนเป็นรถ ❓ X ยิงแล้วบันทึกอย่างน้อย 2 แถว หามวลจาก m = J/Δv
  6. ดูตารางและกราฟ แล้วกรอกคำตอบใน 🎯
⚠️ ความเร็วมีทิศ: ขาไปเป็นบวก ขากลับเป็นลบ · เมื่อรถเด้งกลับ Δv = v₂ − v₁ มีขนาด = |v₁| + |v₂| (มากกว่าตอนชนแล้วหยุด) · วางเกตไกลเซนเซอร์มาก แรงต้านเล็กน้อยของรางจะทำให้ความเร็วที่วัดต่างจากตอนชนจริง

ตารางบันทึกผล (ตัวอย่างหัวตาราง)

m (g) | กันชน | t₁ (ms) | t₂ (ms) | v₁ | v₂ | Δp = m(v₂ − v₁) | F_max (N) | Δt (ms) | J (N·s) | J/Δp | F เฉลี่ย = J/Δt

คำถามท้ายการทดลอง

  1. การดลที่หาจากพื้นที่ใต้กราฟเท่ากับโมเมนตัมที่เปลี่ยนไปหรือไม่ คลาดกันกี่ %
  2. เมื่อ Δp ใกล้เคียงกัน กันชนแบบใดให้แรงสูงสุดน้อยที่สุด เพราะเหตุใด
  3. ทำไมการชนที่รถเด้งกลับจึงได้การดลมากกว่าการชนแบบดินน้ำมันที่รถหยุดนิ่ง
  4. รูปร่างกราฟของดินน้ำมันต่างจากสปริงอย่างไร
  5. ยกตัวอย่างการใช้หลัก “เพิ่มช่วงเวลาการชนเพื่อลดแรง” ในชีวิตประจำวัน 3 ตัวอย่าง

1. การดลและแรงดล

เมื่อแรงกระทำต่อวัตถุในช่วงเวลาหนึ่ง ผลคูณของแรงกับช่วงเวลาเรียกว่า การดล (impulse) ถ้าแรงไม่คงตัว การดลคือพื้นที่ใต้กราฟแรง–เวลา แรงที่กระทำในช่วงเวลาสั้น ๆ ขณะชนเรียกว่า แรงดล

J = F_เฉลี่ย · Δt = พื้นที่ใต้กราฟ F–t (หน่วย N·s)

2. การดลเท่ากับโมเมนตัมที่เปลี่ยนไป

จากกฎข้อที่สองของนิวตัน F = Δp/Δt จะได้

J = Δp = m v₂ − m v₁

ให้ทิศเข้าหาเซนเซอร์เป็นบวก: v₁ > 0 · เด้งกลับ v₂ < 0
ขนาดของ Δp = m ( |v₁| + |v₂| ) (ชนแล้วหยุด: |Δp| = m |v₁|)

เซนเซอร์วัดแรงที่รถกระทำต่อเซนเซอร์ ซึ่งมีขนาดเท่ากับแรงที่เซนเซอร์กระทำต่อรถ (กฎข้อที่สาม) พื้นที่ใต้กราฟจึงเท่ากับขนาดของโมเมนตัมที่เปลี่ยนไปของรถ

3. ช่วงเวลาชนกับแรงสูงสุด

ถ้า Δp เท่ากัน พื้นที่ใต้กราฟต้องเท่ากัน กราฟที่กว้างกว่า (Δt ยาว) จึงต้องเตี้ยกว่า (แรงน้อย) นี่คือหลักของถุงลมนิรภัย หมวกกันน็อก เบาะกระโดดสูง และการย่อเข่าเมื่อกระโดดลงพื้น

F_เฉลี่ย = Δp / Δt กันชนสปริง (กราฟรูปครึ่งไซน์): F_max ≈ (π/2) · F_เฉลี่ย

4. หามวลรถปริศนา X

m_X = J / Δv = J / ( |v₁| + |v₂| ) หรือความชันของกราฟ J – Δv ของรถ X
💡 แบบจำลอง: กันชนสปริงเป็นสปริงมีความหน่วงเล็กน้อย (สปริงแข็ง k ≈ 1500 N/m, สปริงนิ่ม k ≈ 300 N/m) จึงเด้งกลับด้วยอัตราเร็วน้อยกว่าเดิมเล็กน้อย · ดินน้ำมันเป็นแรงหน่วงแบบหนืดที่ขึ้นกับความเร็ว รถจึงหยุดติด · เซนเซอร์แรงบันทึกทุก 1 ms มีสัญญาณรบกวน ±0.03 N · มวลรถ X สุ่ม 250–550 g · รางลมมีความหน่วงเหลือ 0.0004–0.0008 m/s² · เครื่องจับเวลาละเอียด 0.1 ms สัญญาณรบกวน ±0.2 ms
