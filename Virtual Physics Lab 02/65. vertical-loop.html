วัตถุประสงค์

  • หาความสูงต่ำสุดที่ต้องปล่อยวัตถุให้วิ่งผ่านจุดสูงสุดของวงรอบได้โดยไม่หลุดจากราง และเปรียบเทียบกับ h = 2.5R
  • วัดแรงปฏิกิริยาที่จุดสูงสุดและต่ำสุดของวง ตรวจสอบ N_บน = mv²/R − mg และ N_ล่าง = mv²/R + mg
  • เปรียบเทียบวัตถุที่ไถล (รถเข็น) กับวัตถุที่กลิ้ง (ลูกบอล) และหาค่า k ของวัตถุปริศนา

อุปกรณ์ (เสมือนจริง)

  • รางโค้งลงต่อกับวงรอบแนวดิ่ง รัศมี 10–30 cm (เยื้องด้านข้างเล็กน้อยให้วิ่งออกได้) · ไม้บรรทัดวัดความสูง
  • รถเข็นล้อเบามาก (ถือว่าไถลลื่น k ≈ 0) · ลูกเหล็กทรงกลมตันกลิ้ง (k = 0.4) · วัตถุปริศนากลิ้ง (k ไม่ทราบ) · มวล 50 g ทุกชิ้น
  • เซนเซอร์แรง (load cell) ใต้รางที่จุดสูงสุดและต่ำสุดของวง · เครื่องวัดความเร็วแบบประตูแสงที่จุดสูงสุด

การใช้งาน Simulation

  • เลือกวัตถุ ตั้ง R และความสูงปล่อย h (แถบเลื่อนหรือปุ่ม ±0.5, ±5 cm) แล้วกดปุ่ม ▶ ปล่อยวัตถุ ในภาพด้านข้าง (หรือแป้น Space)
  • ผลที่เป็นไปได้: ผ่านวงรอบ · หลุดจากราง (แรงปฏิกิริยาลดเป็นศูนย์ก่อนถึงจุดบน วัตถุตกแบบโพรเจกไทล์) · ไถลกลับ (ขึ้นไปไม่ถึงครึ่งวง)
  • เซนเซอร์แสดงค่าที่วัดได้ขณะวัตถุผ่าน กด 📝 บันทึก หลังการปล่อยแต่ละครั้ง · ปรับความเร็วภาพให้ช้าลงเพื่อดูการหลุดจากราง
  • โหมดวัดเอง: ไม่บอก h ต่ำสุดตามทฤษฎีและค่า k · โหมดอัตโนมัติ: แสดง k, h ต่ำสุด, v และ N ตามทฤษฎี และแรงปฏิกิริยาตลอดเวลา

ขั้นตอน

ตอน A — หาความสูงต่ำสุด

  1. รถเข็น R = 20 cm · ปล่อยที่ h = 60 cm แล้วลดลงทีละ 5 cm จนไม่ผ่าน
  2. หาค่าละเอียดขึ้นทีละ 0.5 cm ระหว่างค่าที่ผ่านกับไม่ผ่าน บันทึกทุกครั้ง
  3. ทำซ้ำกับ R = 15 และ 25 cm · คำนวณ h_min/R

ตอน B — แรงที่จุดบน

  1. R = 20 cm ปล่อยที่ h = 55, 65, 75, 85, 100 cm บันทึก N_บน, v_บน, N_ล่าง
  2. ดูกราฟ N_บน กับ h: เส้นตรงตัดแกน h ที่ h_min

ตอน C — ลูกเหล็กและวัตถุปริศนา

  1. หา h_min ของลูกเหล็ก (ทฤษฎี 2.7R) และของวัตถุปริศนา แล้วคำนวณ k = 2(h_min − 2R)/R − 1

วิธีคำนวณ

อนุรักษ์พลังงาน: mgh = mg(2R) + ½mv²(1 + k) (k = 0 สำหรับวัตถุไถล · 0.4 ลูกทรงกลมตันกลิ้ง)
จุดบน: N + mg = mv²/R → ผ่านได้เมื่อ N ≥ 0 → v² ≥ gR
h_min = 2R + R(1 + k)/2 (k = 0 → 2.5R · k = 0.4 → 2.7R)
N_บน = mg[2(h − 2R)/(R(1 + k)) − 1] N_ล่าง = mg[2h/(R(1 + k)) + 1]

คำถามท้ายการทดลอง

  1. ที่ความสูง h_min แรงปฏิกิริยาที่จุดบนเท่าไร แรงใดทำหน้าที่เป็นแรงสู่ศูนย์กลาง
  2. ถ้าปล่อยต่ำกว่า h_min เล็กน้อย วัตถุหลุดจากรางที่ตำแหน่งใด (ก่อนหรือหลังจุดสูงสุด)
  3. ทำไมลูกเหล็กที่กลิ้งต้องปล่อยสูงกว่ารถเข็น
  4. ที่จุดต่ำสุด แรงปฏิกิริยามากกว่าน้ำหนักกี่เท่า เมื่อปล่อยที่ h_min (คำตอบไม่ขึ้นกับ R)
  5. ถังน้ำที่แกว่งเป็นวงกลมในแนวดิ่ง น้ำไม่หกที่จุดสูงสุดเพราะอะไร เชื่อมโยงกับเงื่อนไข v² ≥ gR อย่างไร

1. แรงที่ตำแหน่งต่าง ๆ ในวงรอบ

  • แรงที่กระทำ: น้ำหนัก mg (ลงเสมอ) และแรงปฏิกิริยา N (ตั้งฉากกับราง ชี้เข้าหาศูนย์กลาง)
  • ที่มุม φ วัดจากจุดต่ำสุด แรงเข้าสู่ศูนย์กลาง = N − mg cos φ = mv²/R จึงได้ N = mv²/R + mg cos φ
  • จุดล่าง (φ = 0): N = mv²/R + mg · จุดบน (φ = 180°): N = mv²/R − mg
  • รางดึงวัตถุไม่ได้ (N ≥ 0 เสมอ) · ถ้าคำนวณได้ N < 0 แปลว่าวัตถุหลุดจากรางไปแล้ว

2. ความสูงต่ำสุด

จุดบน N = 0 → mg = mv²/R → v² = gR
mgh = 2mgR + ½m(gR)(1 + k) → h_min = 2.5R (ไถล) · 2.7R (ทรงกลมตันกลิ้ง)

ถ้าปล่อยต่ำกว่า h_min วัตถุจะหลุดจากรางที่ตำแหน่งที่ N = 0 ซึ่งอยู่ระหว่างครึ่งวงกับจุดสูงสุด (มุม φ ระหว่าง 90° ถึง 180°) แล้วเคลื่อนที่แบบโพรเจกไทล์ตกลงมาภายในวง · ถ้าปล่อยที่ h ≤ R วัตถุขึ้นไปไม่ถึงครึ่งวง (ความเร็วเป็นศูนย์ขณะ N ยังเป็นบวก) จึงไถลกลับโดยไม่หลุด

💡 แบบจำลองใน simulation: รางไม่มีแรงเสียดทานที่ทำให้เสียพลังงาน · วัตถุกลิ้งใช้พลังงานจลน์ ½mv²(1 + k) · ตอนหลุดจากรางคำนวณการเคลื่อนที่แบบโพรเจกไทล์ 2 มิติ เมื่อกระทบรางคงไว้เฉพาะความเร็วตามแนวราง แล้วค่อย ๆ หยุดที่ก้นวง · เซนเซอร์แรงอ่านแรงปฏิกิริยาเฉพาะตอนวัตถุแตะรางตรงตำแหน่งเซนเซอร์ · วัตถุปริศนาสุ่ม k ระหว่าง 0.15–1.0 ต่อการเปิดหน้า · g = 9.81 m/s²
