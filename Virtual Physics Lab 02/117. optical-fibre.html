📝 บันทึกผล

วัตถุประสงค์

  • อธิบายว่าเส้นใยนำแสงพาแสงไปตามแกนได้ด้วยการสะท้อนกลับหมดที่รอยต่อระหว่างแกนกลาง (n₁) กับเปลือก (n₂)
  • เปรียบเทียบมุมที่รังสีกระทบรอยต่อกับมุมวิกฤต θc = sin⁻¹(n₂/n₁) แล้วทำนายว่าแสงจะรั่วออกหรือไม่
  • อธิบายหน้าที่ของเปลือก และผลของการโค้งงอเส้นใย

ใช้ในห้องเรียน 3 นาที (ครูฉายหน้าห้อง)

  1. เปิดหน้าแลป — ค่าเริ่มต้น (n₁ = 1.50, n₂ = 1.46, θ = 15°) แสงสะท้อนกลับหมดซิกแซกไปถึงปลาย ป้าย ✓ สะท้อนกลับหมด
  2. กด 💥 ยิงแสงมุมกว้าง — มุมที่รอยต่อน้อยกว่า θc แสงส่วนใหญ่หักเหออกเปลือก (สีส้ม) แสงในแกนจางลงทุกครั้งที่กระทบ ✗ รั่วออก
  3. กด 🧤 ถอดเปลือก — θc ลดเหลือ 41.81° เส้นใยเปล่าก็ยังนำแสงได้ · แล้วกด 👆 เอานิ้วจับเส้นใย แสงรั่วตรงที่นิ้วจับ → เปลือกช่วยกันผิวแกนกลางไม่ให้สัมผัสสิ่งอื่น
  4. (ถ้ามีเวลา) เลือก ⌒ โค้ง แล้วลดรัศมีความโค้ง — โค้งมากเกินไปแสงจะรั่วที่ผิวด้านนอกของโค้ง

ตารางบันทึก (ใบงาน)

  1. ตั้ง n₁ และ n₂ ตามโจทย์ อ่าน θc จากแผงผล
  2. เพิ่มมุมยิง θ ทีละน้อย (ปุ่ม ±1° / ±0.1°) สังเกตมุมที่รอยต่อ หาค่า θ มากสุดที่ยังขึ้น ✓ สะท้อนกลับหมด
  3. กด 📌 บันทึก ทุกครั้งที่เปลี่ยนค่า ตารางจะเก็บ n₁ n₂ θ มุมที่รอยต่อ θc ผล และแสงที่ออกปลาย
  4. กด แสดง θa เพื่อเทียบค่าที่หาได้กับ sin θa = √(n₁² − n₂²)
ค่าที่ควรได้ · (n₁, n₂) = (1.50, 1.46): θc = 76.74°, θa = 20.13° · (1.50, 1.40): θc = 68.96°, θa = 32.58° · (1.50, 1.00 ถอดเปลือก): θc = 41.81°, √(n₁² − n₂²) = 1.118 เกิน 1 จึงรับแสงได้ทุกมุม

เส้นใยนำแสงทำงานอย่างไร

เส้นใยนำแสงประกอบด้วยแกนกลางดรรชนีหักเห n₁ หุ้มด้วยเปลือกดรรชนีหักเห n₂ ที่น้อยกว่า (n₂ < n₁) แสงที่เดินในแกนกลางไปกระทบรอยต่อด้วยมุมตกกระทบมากกว่ามุมวิกฤต จะสะท้อนกลับหมด ไม่มีแสงหักเหออก จึงสะท้อนซิกแซกไปถึงปลายอีกด้านได้แม้เส้นใยยาวมาก

1) มุมวิกฤตที่รอยต่อแกนกลาง–เปลือก

n₁ sin θc = n₂ sin 90° → θc = sin⁻¹(n₂ / n₁)

มุมที่รังสีกระทบรอยต่อ (วัดจากเส้นแนวฉากของรอยต่อ) ต้อง ≥ θc จึงสะท้อนกลับหมด ถ้าน้อยกว่า θc แสงบางส่วนหักเหออกเปลือก แสงในแกนจะจางลงทุกครั้งที่กระทบ · ถ้า n₂ ≥ n₁ ไม่มีมุมวิกฤต แสงรั่วทุกครั้ง

2) แสงเข้าที่ปลายเส้นใย

n₀ sin θ = n₁ sin θr (อากาศ n₀ = 1)
มุมที่รอยต่อ = 90° − θr (เส้นใยตรง)

ยิ่งยิงแสงเข้าด้วยมุม θ กว้าง θr ยิ่งมาก มุมที่รอยต่อจึงยิ่งน้อย — เมื่อมุมที่รอยต่อน้อยกว่า θc แสงจะรั่ว

3) มุมรับแสงสูงสุด θa (ส่วนขยาย)

ต้องการ 90° − θr ≥ θc → cos θr ≥ n₂/n₁
sin θ = n₁ sin θr ≤ √(n₁² − n₂²) → sin θa = √(n₁² − n₂²)

แสงที่ยิงเข้าภายในกรวยครึ่งมุม θa จะถูกนำไปตามเส้นใยตรง ถ้า √(n₁² − n₂²) ≥ 1 แสงที่เข้าปลายได้ทุกมุมจะถูกนำไปทั้งหมด (รับได้ทุกมุม)

n₁n₂θc ที่รอยต่อ√(n₁² − n₂²)θa

4) ทำไมต้องมีเปลือก และทำไมห้ามโค้งมาก

  • เส้นใยเปล่า (รอบเป็นอากาศ n = 1.00) มีมุมวิกฤตเล็ก นำแสงได้ดี แต่ถ้าผิวแกนกลางแตะนิ้ว น้ำ ฝุ่น หรือเส้นใยข้างเคียง n ภายนอกจะเพิ่มขึ้น แสงรั่วตรงนั้น — เปลือกจึงห่อแกนกลางไว้ให้รอยต่อมี n₂ คงที่เสมอ
  • ช่วงที่โค้ง ผิวด้านนอกของโค้งเอียงเข้าหารังสี มุมที่รอยต่อจึงลดลง ถ้าโค้งแรงจนมุมนั้นน้อยกว่า θc แสงจะรั่ว (ดูค่า "มุมที่รอยต่อ ต่ำสุด" ในโหมดโค้ง)
  • ในแลปนี้ แสงที่รั่วเข้าเปลือกแล้วสะท้อนกลับหมดที่ผิวนอกของเปลือก ถือว่าถูกปลอกหุ้มชั้นนอกดูดกลืน (เส้นใยจริงมีปลอกพลาสติกหุ้มอีกชั้น)
