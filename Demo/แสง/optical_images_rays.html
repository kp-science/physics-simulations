รังสีหลัก 3 เส้น

การหาตำแหน่งภาพด้วยการเขียนแผนภาพรังสี ใช้รังสีจากปลายวัตถุอย่างน้อย 2 เส้น ภาพของปลายวัตถุอยู่ที่จุดตัดของรังสีสะท้อนหรือรังสีหักเห (ภาพจริง) หรือจุดตัดของส่วนต่อของรังสี (ภาพเสมือน)

รังสีกระจกเว้า / กระจกนูนเลนส์นูน / เลนส์เว้า
① ขนานแกนมุขสำคัญสะท้อนผ่าน F (เว้า) · สะท้อนเหมือนออกมาจาก F หลังกระจก (นูน)หักเหผ่าน F อีกด้าน (นูน) · หักเหเหมือนออกมาจาก F ด้านวัตถุ (เว้า)
② ผ่านจุดโฟกัส Fผ่าน F (หรือพุ่งไปยัง F หลังกระจกนูน) → สะท้อนขนานแกนมุขสำคัญผ่าน F ด้านวัตถุ (หรือพุ่งไปยัง F อีกด้านของเลนส์เว้า) → หักเหขนานแกนมุขสำคัญ
③ ผ่าน C / ผ่านขั้วเลนส์ผ่านจุดศูนย์กลางความโค้ง C (ตกตั้งฉากกับผิวกระจก) → สะท้อนกลับทางเดิมผ่านจุดกึ่งกลางเลนส์ (ขั้วเลนส์) → เคลื่อนที่ตรงไปไม่เบี่ยงเบน

กระจกราบไม่มีจุดโฟกัสและจุดศูนย์กลางความโค้ง (f → ∞) จึงใช้รังสีที่ตกตั้งฉาก (สะท้อนกลับทางเดิม) กับรังสีที่ตกที่ขั้วกระจก (มุมตกกระทบ = มุมสะท้อน)

สมการกระจกและเลนส์

1/f = 1/s + 1/s′    m = y′/y = s′/s

s = ระยะวัตถุ · s′ = ระยะภาพ · y = ขนาดวัตถุ · y′ = ขนาดภาพ
s เป็นบวกเสมอ (วัตถุจริง) · s′ เป็นบวก = ภาพจริง · s′ เป็นลบ = ภาพเสมือน · f ของกระจกเว้าและเลนส์นูนเป็นบวก · f ของกระจกนูนและเลนส์เว้าเป็นลบ · R = 2f สำหรับกระจกโค้ง (ในแบบจำลองวาดผิวกระจกเป็นส่วนโค้งวงกลมรัศมี R = 2f จุดศูนย์กลางที่ C จริง มาตราส่วนแนวนอนเท่าแนวดิ่ง)

ภาพเมื่อวัตถุเลื่อนจากไกลมากเข้าหาทัศนอุปกรณ์

ตำแหน่งวัตถุกระจกเว้า · เลนส์นูน
ไกลอนันต์ภาพจริงเป็นจุดที่ F
s > 2fภาพจริง หัวกลับ ย่อ อยู่ระหว่าง f กับ 2f
s = 2fภาพจริง หัวกลับ ขนาดเท่าวัตถุ ที่ 2f
f < s < 2fภาพจริง หัวกลับ ขยาย อยู่ไกลกว่า 2f
s = fรังสีขนานกัน ไม่เกิดภาพ (ภาพอยู่ที่อนันต์)
s < fภาพเสมือน หัวตั้ง ขยาย (กระจก: หลังกระจก · เลนส์: ด้านเดียวกับวัตถุ)
ชิดทัศนอุปกรณ์ภาพเสมือน หัวตั้ง ขนาดเท่าวัตถุ ที่ตำแหน่งเดียวกับวัตถุ
  • กระจกนูน · เลนส์เว้า — ทุกระยะวัตถุให้ภาพเสมือน หัวตั้ง ย่อ อยู่ระหว่างขั้วกับ F · วัตถุไกลมากภาพเล็กลงเข้าใกล้ F · วัตถุชิดภาพเท่าวัตถุ
  • กระจกราบ — ภาพเสมือน หัวตั้ง ขนาดเท่าวัตถุ อยู่หลังกระจก ระยะภาพเท่าระยะวัตถุ (s′ = −s) ทุกระยะ
